## 1. 答案：108

对 6 个正数 $x, \frac{y}{2}, \frac{y}{2}, \frac{z}{3}, \frac{z}{3}, \frac{z}{3}$ 应用 AM-GM 不等式：
$$1 = \frac{x + \frac{y}{2} + \frac{y}{2} + \frac{z}{3} + \frac{z}{3} + \frac{z}{3}}{6} \ge \left(\frac{x y^2 z^3}{4 \cdot 27}\right)^{1/6}$$
故 $x y^2 z^3 \le 108$，当 $x=1, y=2, z=3$ 时取等。

## 2. 答案：15916

设 $a_n(j)$ 为长度 $n$、末位为 $j \in \{0,1,2,3\}$ 的合法串按 $t^{\sum d_i}$ 加权之和，$A_n(t) = \sum_{j=0}^3 a_n(j)$，$G(x) = \sum_{n \ge 1} A_n(t) x^n$。由递推 $a_{n+1}(j) = t^j (A_n - a_n(j))$ 得
$$1 + G(x) = \frac{1}{1 - \sum_{j=0}^3 \frac{t^j x}{1 + t^j x}}.$$
当 $t = \omega^k$（$k=1,2,3,4$，5 次本原单位根）时，令 $u = t^4 x$（满足 $u^5 = x^5$），利用 $\sum_{j=0}^4 \frac{t^j x}{1+t^j x} = \frac{5x^5}{1+x^5}$ 得
$$1 + G(x) = \frac{1 + u^5}{1 + u - u^2 + u^3 - u^4 - 3u^5} = \sum_{n \ge 0} c_n u^n.$$
递推 $c_n = -c_{n-1} + c_{n-2} - c_{n-3} + c_{n-4} + 3c_{n-5} + \delta_{n,5}$（$c_0 = 1$）依次给出：
$c_0=1, c_1=-1, c_2=2, c_3=-4, c_4=8, c_5=-11, c_6=22, c_7=-39, c_8=68, c_9=-116, c_{10}=212$。

因 $t^{40} = 1$，对四个本原单位根均有 $A_{10}(\omega^k) = c_{10} = 212$；而 $A_{10}(1) = 4 \cdot 3^9 = 78732$。由单位根过滤得
$$N = \frac{78732 + 4 \times 212}{5} = \frac{79580}{5} = 15916.$$

## 3. 答案：52165

条件 $f^3(x) = f(x)$ 等价于：设像集 $I = f(S)$（$|I| = k \ge 1$），则 $f|_I$ 为 $I$ 上的对合（involution，$f^2|_I = \mathrm{id}_I$），且每个 $x \in S \setminus I$ 任意映射到 $I$ 中元素（$k^{7-k}$ 种）。

$k$ 元集合的对合数 $a_k$ 满足 $a_0=1, a_1=1, a_k = a_{k-1} + (k-1)a_{k-2}$，得 $a_1 \dots a_7 = 1, 2, 4, 10, 26, 76, 232$。求和：
$$\sum_{k=1}^7 \binom{7}{k} a_k k^{7-k} = 7 + 1344 + 11340 + 22400 + 13650 + 3192 + 232 = 52165.$$

## 4. 答案：116280

$n = 2^{20}$ 不满足条件（$2^{20} \equiv 1 \pmod 3$），而 $n = 0$ 满足条件，故只需统计 $0 \le n \le 2^{20}-1$ 的个数再减 1。

将 $n = \sum_{j=0}^{19} b_j 2^j$ 的二进制位分为 10 个偶数位（1 的个数为 $E$）和 10 个奇数位（1 的个数为 $O$）。则 $s_2(n) = E + O$，$n \equiv E - O \pmod 3$。两者皆被 3 整除等价于 $E \equiv 0 \pmod 3$ 且 $O \equiv 0 \pmod 3$。

10 个位中选出 3 的倍数个 1 的方法数为
$$M = \binom{10}{0} + \binom{10}{3} + \binom{10}{6} + \binom{10}{9} = 1 + 120 + 210 + 10 = 341.$$
因此答案为 $341^2 - 1 = 340 \times 342 = 116280$。

## 5. 答案：27

由韦达跳跃（IMO 1988 P6），$k = \frac{a^2+b^2}{ab+1}$ 必为完全平方数 $m^2$（$m \ge 1$），且对每个固定 $m$，所有正整数解（按 $a \le b$）恰好由递推 $x_0 = 0, x_1 = m, x_{n+1} = m^2 x_n - x_{n-1}$ 的相邻项 $(x_n, x_{n+1})$（$n \ge 1$）给出：

* $m = 1$：仅 $(1, 1)$，贡献 1 个有序对。
* $m \ge 2$：各链严格递增，每个满足 $x_{n+1} \le 1000$ 的无序对贡献 2 个有序对：
  * $n = 1$：$(m, m^3)$，$m \in \{2,3,\dots,10\}$（$10^3 = 1000$），共 9 对；
  * $n = 2$：$(m^3, m^5 - m)$，$m=2 \to (8, 30)$，$m=3 \to (27, 240)$（$m=4 \to 1020 > 1000$），共 2 对；
  * $n = 3$：$m=2 \to (30, 112)$，共 1 对；
  * $n = 4$：$m=2 \to (112, 418)$（下一项 $1560 > 1000$），共 1 对。

总计 $1 + 2 \times (9 + 2 + 1 + 1) = 27$。

## 6. 答案：37325

按列做轮廓线 DP。设覆盖前 $n$ 列后伸入第 $n+1$ 列的 3 位掩码为状态，利用上下对称性，从 `000` 出发的可达状态仅含 4 类：
* $A_n$（`000`）、$B_n$（`100` 与 `001` 之一）、$D_n$（`110` 与 `011` 之一）、$F_n$（`111`）。

转移关系为：
* $A_n = 2B_{n-1} + F_{n-1}$，$B_n = A_{n-1} + D_{n-1}$，$D_n = 2B_{n-1}$，$F_n = 3A_{n-1}$（初值 $A_0=1$，其余为 0）。

令 $a_k = A_{2k}$，消元得 $a_0 = 1, a_1 = 5$，且 $a_k = 7a_{k-1} - 6a_{k-2}$，通项为 $a_k = \frac{4 \cdot 6^k + 1}{5}$。
对 $3 \times 12$（$k = 6$）：
$$a_6 = \frac{4 \cdot 6^6 + 1}{5} = \frac{4 \cdot 46656 + 1}{5} = \frac{186625}{5} = 37325.$$

## 7. 答案：11

由余弦定理 $\cos A = \frac{15^2 + 7^2 - 13^2}{2 \cdot 15 \cdot 7} = \frac{105}{210} = \frac{1}{2}$，故 $\angle A = 60^\circ$。

建系取 $A(0,0)$，$C(15,0)$，$B\left(\frac{7}{2}, \frac{7\sqrt{3}}{2}\right)$：
* 外心 $O = \left(\frac{15}{2}, -\frac{\sqrt{3}}{6}\right)$（满足 $x_O = \frac{15}{2}$ 且 $x_O + \sqrt{3} y_O = 7$）；
* 垂心 $H = A + B + C - 2O = \left(\frac{7}{2}, \frac{23\sqrt{3}}{6}\right)$；
* 内心 $I = \frac{13A + 15B + 7C}{35} = \left(\frac{9}{2}, \frac{3\sqrt{3}}{2}\right)$。

得 $\overrightarrow{OH} = (-4, 4\sqrt{3})$，$\overrightarrow{OI} = \left(-3, \frac{5\sqrt{3}}{3}\right)$，面积为
$$S_{\triangle OIH} = \frac{1}{2}\left|(-4)\cdot \frac{5\sqrt{3}}{3} - 4\sqrt{3}\cdot(-3)\right| = \frac{1}{2} \cdot \frac{16\sqrt{3}}{3} = \frac{8\sqrt{3}}{3}.$$
故 $m = 8, n = 3$，$m + n = 11$。

## 8. 答案：15702

设禁用棋盘 $B_n = \{(i, j) : 1 \le i, j \le n,\ |i - j| \le 1\}$，其车多项式为 $A_n(x) = \sum_{k=0}^n r_k(B_n) x^k$。按行做 4 状态 DP（追踪列 $i-1$ 与列 $i$ 是否已占用），化简后仅需两个多项式序列 $A_i(x), P_i(x)$：
* 初值：$A_0 = 1, P_0 = 0$；$A_1 = 1+x, P_1 = 1$；
* 递推：$P_i = x P_{i-1} + A_{i-1}$，$A_i = (1+x)A_{i-1} + x P_{i-1} + (x+x^2)A_{i-2} + x^2 P_{i-2}$。

逐项推至 $n = 9$（并经 $x=1, x=-1$ 校验和验证）得：
$$A_9(x) = 1 + 25x + 254x^2 + 1356x^3 + 4115x^4 + 7191x^5 + 7018x^6 + 3538x^7 + 789x^8 + 55x^9.$$
由容斥原理：
$$N_9 = \sum_{k=0}^9 (-1)^k r_k(B_9)(9-k)! = (362880 + 1280160 + 493800 + 42108 + 789) - (1008000 + 976320 + 172584 + 7076 + 55)$$
$$= 2179737 - 2164035 = 15702.$$
