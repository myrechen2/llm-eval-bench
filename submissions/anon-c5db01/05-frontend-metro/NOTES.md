# 任务 05 · 地铁线路规划器说明

## 设计思路
- **单文件离线应用**：所有样式、SVG 渲染引擎、路径规划算法与示例线网数据全部内联在 `index.html` 中，不依赖任何外部资源或网络请求，双击即可运行。
- **自适应线网绘制**：
  - 将任意正数范围的 `(x, y)` 站点坐标等比例缩放映射到 `1200×840` 的虚拟 SVG 画布并留出边距；支持鼠标滚轮缩放、背景拖拽平移及按钮缩放/重置。
  - 同一对相邻站点的多条并行线路通过法向量垂直偏移并行绘制，避免互相遮挡；环线（`loop: true`）自动闭合首尾线段；换乘站采用双层圆环视觉区分。
  - 对 140 站以下线网采用 8 方向贪心避让算法自动摆放站名标注，减少与站名、站点圆点和轨道线段的重叠。
- **交互与响应式**：
  - 支持地图点选与输入框自动补全（`Enter` 精确/候选选中）、起终点互换、最短时间/最少换乘即时切换、图例点击高亮单条线路，以及跟随系统并支持手动切换的浅色/深色主题。
  - 桌面端（1440×900）采用左侧规划栏 + 右侧全高线网图布局，移动端（390×844）自动切换为上下流式布局并限制横向溢出（无横向滚动条）。

## 核心路径算法
- **状态空间建模**：将每条线路上经过的站点建模为乘车状态 `(station, line)`，并在存在多条线路交汇的站点引入中转枢纽节点 `(station, HUB)`：
  - 同一线路相邻站边权为 `(dt = times[i], tr = 0)`（环线含末站到首站）。
  - `(station, line) -> (station, HUB)` 边权为 `(dt = transferCost(station), tr = 1)`（显式区分 `transferTime === 0` 与未设置）；`(station, HUB) -> (station, line')` 边权为 `(0, 0)`。
  - 起点从所有经过该站的 `(from, line)` 以 `(0, 0)` 同时入堆；首次从最小堆弹出任一 `(to, line)` 即为最优解。
- **排序与复杂度**：使用二叉最小堆实现字典序 Dijkstra（`"time"` 模式比较 `(time, transfers)`，`"transfers"` 模式比较 `(transfers, time)`）。引入 `HUB` 节点使换乘站边数从 $O(k^2)$ 降至 $O(k)$，图在 `loadNetwork` 时预构建；经 Node.js 验证，示例线网全对（1369 组×2 模式）及含 0 分钟换乘/并行线路/环线回绕/孤立站的边界用例全部通过，320 站网格线网单次 `route()` 耗时约 0.2 ms。

## 已知不足
- 当线网规模超过 140 站时，为保证首屏渲染流畅，站名标注切换为固定偏移，未做全局碰撞避让；此外未引入外部真实浏览器环境做像素级截图检查，界面布局通过 CSS 响应式规则与节点/算法脚本校验保证。
