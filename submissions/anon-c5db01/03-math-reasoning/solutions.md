# 任务 03 · 数学推理题解

## 第 1 题
由算术-几何平均不等式（AM-GM）：
$$6 = x + \frac{y}{2} + \frac{y}{2} + \frac{z}{3} + \frac{z}{3} + \frac{z}{3} \ge 6 \left(x \cdot \frac{y^2}{4} \cdot \frac{z^3}{27}\right)^{1/6}$$
于是 $x y^2 z^3 \le 4 \cdot 27 = 108$，当 $x=1, y=2, z=3$ 时取等。

**答案：108**

## 第 2 题
设 $F_n(z)$ 为所有长度为 $n$、相邻数字不同的 $\{0,1,2,3\}$ 数字串的 $z^{\sum d_i}$ 之和，使用 5 次单位根滤波：所求数量为 $\frac{1}{5} \sum_{k=0}^4 F_{10}(\zeta^k)$，其中 $\zeta = e^{2\pi i/5}$。
- 当 $z=1$ 时，$F_{10}(1) = 4 \cdot 3^9 = 4 \cdot 19683 = 78732$。
- 当 $z \ne 1$ 且 $z^5=1$ 时，记 $v_n = (S_{n,0}, S_{n,1}, S_{n,2}, S_{n,3})^T$（按末位数字分类），有 $v_1 = u = (1, z, z^2, z^3)^T$ 及 $v_{n+1} = D(z)(J-I)v_n$。令生成函数 $G(x) = \sum_{n=1}^\infty F_n(z) x^{n-1} = \mathbf{1}^T (I - x D(z)(J-I))^{-1} u$，化简得
  $$G(x) = \frac{R(x)}{1 - x R(x)}, \quad R(x) = \sum_{j=0}^3 \frac{z^j}{1 + x z^j} = \frac{5x^4}{1+x^5} - \frac{u}{1+ux}$$
  其中 $u = z^4$。整理得到
  $$G(x) = \frac{-u + 5x^4 + 4ux^5}{1 + 2ux - 4x^5 - 3ux^6} = \sum_{m=0}^\infty c_m x^m$$
  令 $c_m = a_m u^{m+1}$（因 $u^5=1$），初值 $a_0=-1, a_1=2, a_2=-4, a_3=8, a_4=-11, a_5=22$，当 $m \ge 6$ 时满足 $a_m = -2a_{m-1} + 4a_{m-5} + 3a_{m-6}$：
  - $a_6 = -44 + 8 - 3 = -39$
  - $a_7 = 78 - 16 + 6 = 68$
  - $a_8 = -136 + 32 - 12 = -116$
  - $a_9 = 232 - 44 + 24 = 212$
  因 $u^{10} = 1$，故对所有非平凡 5 次单位根都有 $F_{10}(z) = c_9 = 212$。

因此结果为
$$\frac{78732 + 4 \times 212}{5} = \frac{79580}{5} = 15916$$

**答案：15916**

## 第 3 题
条件 $f(f(f(x))) = f(x)$ 等价于：记像集 $I = f(S)$，$|I| = k \in \{1, \dots, 7\}$，则 $f|_I$ 是 $I$ 上的对合（$f^2(y) = y$），且 $S \setminus I$ 中的元素可任意映射到 $I$ 中。反之，任意三元组 $(I, f|_I, f|_{S\setminus I})$ 均唯一确定一个满足条件的函数 $f$。

设 $k$ 元集上对合的个数为 $a_k$（由 $a_0=1, a_1=1, a_k = a_{k-1} + (k-1)a_{k-2}$）：
$a_1=1, a_2=2, a_3=4, a_4=10, a_5=26, a_6=76, a_7=232$。

总数为 $\sum_{k=1}^7 \binom{7}{k} a_k k^{7-k}$：
- $k=1$: $7 \times 1 \times 1 = 7$
- $k=2$: $21 \times 2 \times 32 = 1344$
- $k=3$: $35 \times 4 \times 81 = 11340$
- $k=4$: $35 \times 10 \times 64 = 22400$
- $k=5$: $21 \times 26 \times 25 = 13650$
- $k=6$: $7 \times 76 \times 6 = 3192$
- $k=7$: $1 \times 232 \times 1 = 232$

求和：$7 + 1344 + 11340 + 22400 + 13650 + 3192 + 232 = 52165$。

**答案：52165**

## 第 4 题
$n = 2^{20}$ 的二进制仅有 1 个 `1` 且 $2^{20} \equiv 1 \pmod 3$，不满足条件。先在 $0 \le n < 2^{20}$ 中计数，再扣除 $n=0$。

设 $n = \sum_{j=0}^{19} b_j 2^j$（$b_j \in \{0,1\}$），记偶数位上的 `1` 个数为 $e$（共 10 位），奇数位上的 `1` 个数为 $o$（共 10 位）。由于 $2^j \equiv (-1)^j \pmod 3$，有：
- $n \equiv e - o \pmod 3$
- 二进制中 `1` 的个数为 $e + o$

两者均能被 3 整除当且仅当 $3 \mid e$ 且 $3 \mid o$。对 10 个位置选出 $3k$ 个 `1` 的方案数为
$$M = \binom{10}{0} + \binom{10}{3} + \binom{10}{6} + \binom{10}{9} = 1 + 120 + 210 + 10 = 341 = \frac{2^{10}-1}{3}$$
奇偶位相互独立，扣除 $n=0$ 后总数为
$$341^2 - 1 = 116281 - 1 = 116280$$

**答案：116280**

## 第 5 题
设 $k = \frac{a^2+b^2}{ab+1} \in \mathbb{Z}_{>0}$，做 Vieta 跳跃。若 $a \ge b \ge 1$ 为给定 $k$ 下 $a+b$ 最小的解，另一根 $a' = kb - a = \frac{b^2-k}{a}$ 满足 $a' < b \le a$ 且 $a' \ge 0$（若 $a' \le -1$ 则 $a'^2 - kba' + b^2 - k \ge 2 > 0$）。由极小性必有 $a' = 0$，即 $k = m^2$（$m \in \mathbb{Z}_{>0}$），且解由 $x_0 = 0, x_1 = m, x_{n+1} = m^2 x_n - x_{n-1}$ 迭代产生相邻对 $(x_n, x_{n+1})$：
- $m = 1$：序列为 $0, 1, 1, 0, \dots$，得 $(1, 1)$，计 $1$ 对有序正整数对。
- $m \ge 2$：序列严格递增，每对 $(x_n, x_{n+1})$ 贡献 $2$ 个有序对：
  - $n=1$，$(m, m^3)$：$m^3 \le 1000 \implies 2 \le m \le 10$（9 个 $m$，共 $18$ 对）。
  - $n=2$，$(m^3, m^5-m)$：$m=2$ 时为 $(8, 30)$；$m=3$ 时为 $(27, 240)$；$m=4$ 时 $1020 > 1000$（2 个 $m$，共 $4$ 对）。
  - $n=3$，$(m^5-m, m^7-2m^3)$：仅 $m=2$ 满足，为 $(30, 112)$（$2$ 对）。
  - $n=4$，$m=2$ 时为 $(112, 418)$（$2$ 对）。
  - $n=5$，$m=2$ 时 $x_6 = 4 \cdot 418 - 112 = 1560 > 1000$，终止。

总计 $1 + 18 + 4 + 2 + 2 = 27$ 对。

**答案：27**

## 第 6 题
用列轮廓动态规划。由于所有砖块面积均为偶数，且每推进一列轮廓中“已覆盖格数”奇偶性翻转，奇数列进入时的可能轮廓（偶数个 `1`）只有 `000`、`110`、`011`、`101`（其中 `101` 无法从 `000` 到达）。

经两列（从奇数列到下一奇数列）的转移：
- `000` $\to$ `100`(1), `001`(1), `111`(3)（分别为 3 个 $1\times 2$ 横牌，或 1 个 $2\times 2$ 配 1 个 $1\times 2$ 的上下两种摆法）。再走一列：
  - `100` $\to$ `000`(1), `011`(2)（两横牌或一个 $2\times 2$）
  - `001` $\to$ `000`(1), `110`(2)
  - `111` $\to$ `000`(1)
  汇总两列转移：`000` $\to$ `000`(5), `110`(2), `011`(2)；`110` $\to$ `000`(1), `110`(2)；`011` $\to$ `000`(1), `011`(2)。

设 $3 \times (2k)$ 矩形的方案数为 $A_k$，以 `110` 结束的方案数为 $B_k$（由对称性 `011` 同为 $B_k$），则 $A_0=1, B_0=0$，
$$A_{k+1} = 5 A_k + 2 B_k, \quad B_{k+1} = 2 A_k + 2 B_k$$
消元得 $A_{k+1} = 7 A_k - 6 A_{k-1}$，通解为 $A_k = \frac{4 \cdot 6^k + 1}{5}$。当 $2k = 12$ 即 $k = 6$ 时：
$$A_6 = \frac{4 \cdot 6^6 + 1}{5} = \frac{4 \cdot 46656 + 1}{5} = \frac{186625}{5} = 37325$$

**答案：37325**

## 第 7 题
由余弦定理，$\cos A = \frac{7^2 + 15^2 - 13^2}{2 \cdot 7 \cdot 15} = \frac{105}{210} = \frac{1}{2}$，故 $A = 60^\circ$。建立直角坐标系：$A=(0,0)$，$B=(7,0)$，$C=\left(\frac{15}{2}, \frac{15\sqrt{3}}{2}\right)$。

- **外心 $O$**：$x_O = \frac{7}{2}$，由 $OA^2 = OC^2$ 解得 $y_O = \frac{23\sqrt{3}}{6}$，即 $O = \left(\frac{7}{2}, \frac{23\sqrt{3}}{6}\right)$。
- **垂心 $H$**：由 $H = A + B + C - 2O$ 得 $H = \left(\frac{15}{2}, -\frac{\sqrt{3}}{6}\right)$。
- **内心 $I$**：周长 $a+b+c = 13+15+7 = 35$，
  $$I = \frac{13 A + 15 B + 7 C}{35} = \left(\frac{9}{2}, \frac{3\sqrt{3}}{2}\right)$$

计算向量 $\overrightarrow{IO} = \left(-1, \frac{7\sqrt{3}}{3}\right)$，$\overrightarrow{IH} = \left(3, -\frac{5\sqrt{3}}{3}\right)$，面积为
$$S_{\triangle OIH} = \frac{1}{2} |\overrightarrow{IO} \times \overrightarrow{IH}| = \frac{1}{2} \left| (-1)\left(-\frac{5\sqrt{3}}{3}\right) - \frac{7\sqrt{3}}{3} \cdot 3 \right| = \frac{1}{2} \cdot \frac{16\sqrt{3}}{3} = \frac{8\sqrt{3}}{3}$$
故 $m = 8, n = 3$，$m + n = 11$。

**答案：11**

## 第 8 题
禁止位置集合为三对角带 $B_n = \{(i, j) : 1 \le i, j \le n,\ |i-j| \le 1\}$。设 $R_n(x) = \sum_{k=0}^n r_k(B_n) x^k$ 为 $B_n$ 的车多项式，$D_n(x)$ 为 $B_n$ 删去最后一行后的车多项式。由容斥原理，$f(n) = \sum_{k=0}^n (-1)^k r_k(B_n) (n-k)!$。

按第 $n$ 行与第 $n$ 列是否有车分类，得递推：
$$D_n(x) = R_{n-1}(x) + x D_{n-1}(x), \quad R_n(x) = D_n(x) + x R_{n-1}(x) + x D_{n-1}(x) + x^2 R_{n-2}(x)$$
初值 $R_0 = 1, R_1 = 1+x, D_1 = 1$。依次展开至 $n=9$：
- $R_2 = 1 + 4x + 2x^2$，$D_2 = 1 + 2x$
- $R_3 = 1 + 7x + 11x^2 + 3x^3$，$D_3 = 1 + 5x + 4x^2$
- $R_4 = 1 + 10x + 29x^2 + 26x^3 + 5x^4$，$D_4 = 1 + 8x + 16x^2 + 7x^3$
- $R_5 = 1 + 13x + 56x^2 + 94x^3 + 56x^4 + 8x^5$，$D_5 = 1 + 11x + 37x^2 + 42x^3 + 12x^4$
- $R_6 = 1 + 16x + 92x^2 + 234x^3 + 263x^4 + 114x^5 + 13x^6$，$D_6 = 1 + 14x + 67x^2 + 131x^3 + 98x^4 + 20x^5$
- $R_7 = 1 + 19x + 137x^2 + 473x^3 + 815x^4 + 667x^5 + 223x^6 + 21x^7$，$D_7 = 1 + 17x + 106x^2 + 301x^3 + 394x^4 + 212x^5 + 33x^6$
- $R_8 = 1 + 22x + 191x^2 + 838x^3 + 1982x^4 + 2504x^5 + 1577x^6 + 424x^7 + 34x^8$，$D_8 = 1 + 20x + 154x^2 + 579x^3 + 1116x^4 + 1061x^5 + 435x^6 + 54x^7$
- $D_9 = 1 + 23x + 211x^2 + 992x^3 + 2561x^4 + 3620x^5 + 2638x^6 + 859x^7 + 88x^8$
- $R_9 = 1 + 25x + 254x^2 + 1356x^3 + 4115x^4 + 7191x^5 + 7018x^6 + 3538x^7 + 789x^8 + 55x^9$

代入容斥公式计算 $f(9)$：
$$f(9) = 9! - 25\cdot 8! + 254\cdot 7! - 1356\cdot 6! + 4115\cdot 5! - 7191\cdot 4! + 7018\cdot 3! - 3538\cdot 2! + 789\cdot 1! - 55\cdot 0!$$
$$= 362880 - 1008000 + 1280160 - 976320 + 493800 - 172584 + 42108 - 7076 + 789 - 55 = 15702$$

**答案：15702**
