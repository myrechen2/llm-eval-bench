# Task 04 · ARC 规则总结

所有 10 道题均在各自全部 `train` 样例上通过了精确一致验证:

* **01**: 向下重力下落——每列所有非零格子保持纵向相对顺序落至网格底部。
* **02**: 识别颜色 `5` 的 4-连通分量,面积最大的改为 `1`,面积最小的改为 `2`,其余保持 `5`。
* **03**: 对每个 `5` 及其四邻域中的非零颜色 `c`,从 `c` 出发沿背离 `5` 的方向发射颜色为 `c` 的射线直至网格边界。
* **04**: 以整列 `5` 为分隔线,将左右两个等宽子网格按非零/零做逐格异或(XOR),结果为真处填颜色 `3`,否则填 `0`。
* **05**: 在旋转和镜像等价意义下,找出网格中唯一形状不重复的 4-连通非零图形,输出其最小外接矩形。
* **06**: 网格是由周期块平铺并挖去若干 `0` 形成的;推断最小二维周期 `(pr, pc)` 补全所有 `0` 格。
* **07**: 将被 `1` 完全封闭(无法通过 4-连通 `0` 格到达网格边界)的内部 `0` 区域填充为 `4`,开口区域保持 `0`。
* **08**: 整行 `5` 上方为颜色映射表(第 0 行映射到同列第 1 行);分隔线下方所有非零色按映射表**同时**替换,未出现在第 0 行的颜色清除为 `0`。
* **09**: 整行或整列的 `8` 为边界墙;所有 4-连通同色刚体沿朝向 `8` 墙的方向平移下落,直至碰到墙体或其他刚体并稳定堆积。
* **10**: 统计每个颜色 `5` 的 4-连通分量内部封闭空洞(4-连通 `0` 区域)的数量 `k`:`k = 0` 则删除为 `0`,`k >= 1` 则将该分量重着色为 `k`。
