# Task 05 · 地铁线路规划器说明

## 设计思路

* **单文件零依赖**:全部 HTML、CSS、JavaScript 及示例线网数据均内联于 `index.html`,不引用任何外部字体、图标或接口,可直接通过 `file://` 打开运行。
* **信息层级与视觉**:桌面端采用左侧控制/行程面板 + 右侧全高交互式 SVG 地图的双栏布局;手机竖屏(≤820px)自动切换为上下堆叠且确保零横向溢出。支持系统 `prefers-color-scheme` 自动深色模式及手动深浅色切换。
* **地图渲染细节**:
  * **自适应缩放**:根据站点坐标包围盒与相邻站距中位数自动计算 `viewBox`、线宽、站点半径和字号,兼顾几十站示例线网与数百站大线网。
  * **并行线路分离**:对共享同一对相邻站点的多条线路按法向量自动偏移,确保并行线均清晰可见;环线(`loop: true`)首尾闭合。
  * **换乘站与防遮挡标注**:换乘站(≥2 条线)采用双环节点突出展示;站名标注基于 8 方向候选评分(避让相邻轨道方向、其他站点与已放置标签包围盒),配背景描边光晕确保可读性;起终点 `起`/`终` 气泡自动放置在站名标注的对侧避免遮挡。
  * **交互增强**:支持地图点击选站、输入联想与完整站名回车选中、模式切换、起终点交换、图例单线高亮、滚轮缩放/拖拽平移及键盘操作。

## 路径规划算法

* **状态扩展图 + 中转枢轴(Hub)**:
  * 每个站-线对 `(s, l)` 为一个乘车状态;对换乘站额外设立一个枢轴节点 `HUB(s)`。
  * 同线相邻区间 `(u, l) <-> (v, l)` 权重为 `(edgeTime, 0)`(环线自动连接首尾站,双向同权)。
  * 换乘通过 `(s, l) -> HUB(s)` 权重 `(transferCost(s), 1)` 与 `HUB(s) -> (s, l')` 权重 `(0, 0)` 实现,将单站换乘边数从 $O(k^2)$ 降至 $O(k)$。换乘时间严格采用 `typeof st.transferTime === "number" ? st.transferTime : defaultTransfer`,正确保留 `0` 分钟换乘。
* **词典序二叉堆 Dijkstra**:
  * 起点所有经停线路 `(from, l)` 以 `(0, 0)` 入堆(上车不计时间);到达任一 `(to, l)` 即提前结束。
  * `"time"` 模式按 `(totalTime, transfers)` 最小化;`"transfers"` 模式按 `(transfers, totalTime)` 最小化。
  * 在 350 站 18 线的随机大线网上单次查询平均耗时 < 0.1 ms,远低于 200 ms 限制,并与独立参考实现在示例全量点对、零换乘时间、并行线、环线及孤立站用例上交叉验证一致。

## 已知不足

* 极高密度(>300 站)且坐标高度聚集的大线网在默认全览视图下站名仍可能较为紧凑,需借助滚轮缩放或拖拽查看局部细节。
* 未对触摸屏双指捏合手势(pinch-to-zoom)做专门处理,移动端缩放可通过右下角 `+` / `−` / 重置按钮完成。
