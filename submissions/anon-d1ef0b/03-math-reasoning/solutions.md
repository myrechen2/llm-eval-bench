# Task 03 · 数学推理题解

## 第 1 题(答案:108)

将已知条件改写为 6 个正数之和:
$$x + \frac{y}{2} + \frac{y}{2} + \frac{z}{3} + \frac{z}{3} + \frac{z}{3} = 6.$$
由六元 AM-GM 不等式:
$$\left(x \cdot \left(\frac{y}{2}\right)^2 \cdot \left(\frac{z}{3}\right)^3\right)^{1/6} \le \frac{6}{6} = 1 \implies x y^2 z^3 \le 2^2 \cdot 3^3 = 108.$$
当且仅当 $x = \frac{y}{2} = \frac{z}{3} = 1$,即 $(x, y, z) = (1, 2, 3)$ 时取等号。最大值为 **108**。

## 第 2 题(答案:15916)

利用 5 次单位根滤波:设 $\omega = e^{2\pi i/5}$,记
$$F_n(\zeta) = \sum_{\substack{a_1,\dots,a_n \in \{0,1,2,3\} \\ a_j \ne a_{j+1}}} \zeta^{a_1 + \dots + a_n},$$
则答案为 $\frac{1}{5} \sum_{k=0}^{4} F_{10}(\omega^k)$。

* 当 $\zeta = 1$ 时,$F_{10}(1) = 4 \cdot 3^9 = 4 \cdot 19683 = 78732$。
* 当 $\zeta$ 为本原 5 次单位根时,设 $v_n(a)$ 为长度 $n$ 且末位为 $a$ 的带权和,$G(x) = \sum_{n \ge 1} F_n(\zeta) x^n$,$V_a(x) = \sum_{n \ge 1} v_n(a) x^n$。由递推 $v_1(a) = \zeta^a$、$v_{n+1}(a) = \zeta^a(F_n(\zeta) - v_n(a))$ 得:
  $$V_a(x)(1 + \zeta^a x) = \zeta^a x (1 + G(x)) \implies 1 + G(x) = \frac{1}{1 - S(x)}, \quad S(x) = \sum_{a=0}^{3} \frac{\zeta^a x}{1 + \zeta^a x}.$$
  因为 $\sum_{a=0}^{4} \frac{\zeta^a x}{1 + \zeta^a x} = \frac{5x^5}{1 + x^5}$,令 $u = \zeta^4 x$(则 $u^5 = x^5$),有
  $$S(x) = \frac{5u^5}{1 + u^5} - \frac{u}{1 + u}, \qquad 1 + G(x) = \frac{(1 + u)(1 + u^5)}{1 + 2u - 4u^5 - 3u^6} = \frac{1 + u^5}{1 + u - u^2 + u^3 - u^4 - 3u^5}.$$
  记展开系数为 $c_n = [u^n](1 + G(x))$,则 $F_{10}(\zeta) = c_{10} \zeta^{40} = c_{10}$ 对所有 4 个本原单位根相同。
  由递推 $c_n = -2c_{n-1} + 4c_{n-5} + 3c_{n-6} + [u^n](1+u+u^5+u^6)$ 依次算得:
  $$c_0=1,\; c_1=-1,\; c_2=2,\; c_3=-4,\; c_4=8,\; c_5=-11,\; c_6=22,\; c_7=-39,\; c_8=68,\; c_9=-116,\; c_{10}=212.$$

因此总数为 $\frac{78732 + 4 \times 212}{5} = \frac{79580}{5} = \mathbf{15916}$。

## 第 3 题(答案:52165)

设像集 $I = f(S)$,$|I| = k \in \{1,\dots,7\}$。对任意 $y = f(x) \in I$,条件 $f^3(x) = f(x)$ 等价于 $f(f(y)) = y$,即 $f|_I: I \to I$ 为 $I$ 上的对合(每个元素要么是不动点,要么在 2-循环中)。反过来,任选非空子集 $I$(大小 $k$)、$I$ 上任一对合 $g$、以及对每个 $x \in S \setminus I$ 任选 $f(x) \in I$,由于 $g$ 是双射,像集仍恰为 $I$,且对任意 $x \in S$ 都有 $f^3(x) = g^2(f(x)) = f(x)$。

设 $a_k$ 为 $k$ 元集上对合的个数,由 $a_k = a_{k-1} + (k-1)a_{k-2}$ 得:
$$a_1=1,\; a_2=2,\; a_3=4,\; a_4=10,\; a_5=26,\; a_6=76,\; a_7=232.$$
故总数为
$$\sum_{k=1}^{7} \binom{7}{k} a_k k^{7-k} = 7\cdot 1\cdot 1 + 21\cdot 2\cdot 32 + 35\cdot 4\cdot 81 + 35\cdot 10\cdot 64 + 21\cdot 26\cdot 25 + 7\cdot 76\cdot 6 + 1\cdot 232\cdot 1$$
$$= 7 + 1344 + 11340 + 22400 + 13650 + 3192 + 232 = \mathbf{52165}.$$

## 第 4 题(答案:116280)

$n = 2^{20}$ 满足 $2^{20} \equiv 1 \pmod 3$,不合题意;先统计 $0 \le n \le 2^{20}-1$,最后减去 $n = 0$。

将 $n$ 写成 20 位二进制 $\sum_{j=0}^{19} b_j 2^j$,记偶数位($j=0,2,\dots,18$,共 10 位)中 1 的个数为 $E$,奇数位($j=1,3,\dots,19$,共 10 位)中 1 的个数为 $O$。因为 $2^j \equiv (-1)^j \pmod 3$,条件为:
$$E - O \equiv 0 \pmod 3 \quad \text{且} \quad E + O \equiv 0 \pmod 3 \iff E \equiv 0 \pmod 3 \text{ 且 } O \equiv 0 \pmod 3.$$
偶数位与奇数位完全独立,各自方案数为
$$A = \binom{10}{0} + \binom{10}{3} + \binom{10}{6} + \binom{10}{9} = 1 + 120 + 210 + 10 = 341 = \frac{2^{10}-1}{3}.$$
去掉 $n = 0$,答案为 $341^2 - 1 = 340 \times 342 = \mathbf{116280}$。

## 第 5 题(答案:27)

设 $k = \frac{a^2 + b^2}{ab + 1} \in \mathbb{Z}^+$,即 $a^2 - kab + b^2 = k$。由经典的韦达跳跃(Vieta jumping),对任意正整数解,若 $a \ge b \ge 1$:
* 当 $a = b$ 时 $2a^2 = k(a^2+1) \implies a = b = 1, k = 1$,仅得 1 个有序对 $(1, 1)$。
* 当 $a > b \ge 1$ 时,另一根 $a' = kb - a = \frac{b^2 - k}{a}$ 满足 $0 \le a' < b$,因此任意正整数解沿唯一向下跳跃必终止于 $(m, 0)$,其中 $k = m^2$($m \ge 2$)。

反之,对每个 $m \ge 2$,从 $x_0 = 0, x_1 = m$ 按 $x_{n+1} = m^2 x_n - x_{n-1}$ 递增生成全部无序解 $(x_{n+1}, x_n)$($n \ge 1$):
* $n = 1$: $(m^3, m)$,满足 $m^3 \le 1000$ 的有 $m = 2, 3, \dots, 10$,共 **9** 组。
* $n = 2$: $(m^5 - m, m^3)$:$m=2$ 得 $(30, 8)$,$m=3$ 得 $(240, 27)$,$m=4$ 时 $4^5-4 = 1020 > 1000$,共 **2** 组。
* $n = 3$: $m=2$ 得 $(112, 30)$,$m=3$ 时 $2133 > 1000$,共 **1** 组。
* $n = 4$: $m=2$ 得 $(418, 112)$,共 **1** 组。
* $n = 5$: $m=2$ 得 $x_6 = 4 \cdot 418 - 112 = 1560 > 1000$,无解。

共有 $9 + 2 + 1 + 1 = 13$ 组满足 $a > b$ 的无序解,加上 $(1, 1)$,有序对总数为 $1 + 2 \times 13 = \mathbf{27}$。

## 第 6 题(答案:37325)

对 $3 \times n$ 矩形按列做轮廓线 DP。所有砖块面积均为偶数,故偶数列后轮廓只能为 `000`、`110`、`011`(`101` 不可达),奇数列后轮廓只能为 `100`、`001`、`111`(`010` 不可达)。由上下对称性,记第 $2m$ 列后到达 `000` 的方案数为 $a_m$,到达 `110`(或 `011`)的方案数为 $b_m$;第 $2m+1$ 列后到达 `100`(或 `001`)的方案数为 $p$,到达 `111` 的方案数为 $r$:

* 偶列 $\to$ 奇列:
  * 从 `000` 放 1 块竖骨牌 + 1 块横骨牌得 `100`(1 种)或 `001`(1 种);三行全向右伸出得 `111` 有 **3** 种(三块横骨牌,或上/下 $2\times 2$ 方块配 1 块横骨牌)。
  * 从 `110` 必得 `001`(1 种),从 `011` 必得 `100`(1 种)。
  * 故 $p = a_m + b_m$,$r = 3 a_m$。
* 奇列 $\to$ 偶列:
  * 从 `100`(或 `001`)可放竖骨牌回 `000`(1 种),或两行一起向右伸出得 `011`(或 `110`)有 **2** 种(两块横骨牌或 1 块 $2\times 2$ 方块)。
  * 从 `111` 必回 `000`(1 种)。
  * 故 $a_{m+1} = 2p + r = 5 a_m + 2 b_m$,$b_{m+1} = 2p = 2 a_m + 2 b_m$。

消去 $b_m$ 得 $a_{m+1} = 7 a_m - 6 a_{m-1}$,初值 $a_0 = 1, a_1 = 5$,通项为
$$a_m = \frac{4 \cdot 6^m + 1}{5}.$$
当 $n = 12$($m = 6$)时,$6^6 = 46656$,故
$$a_6 = \frac{4 \times 46656 + 1}{5} = \frac{186625}{5} = \mathbf{37325}.$$

## 第 7 题(答案:11)

设 $a = BC = 13$,$b = CA = 15$,$c = AB = 7$。由余弦定理:
$$\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{225 + 49 - 169}{210} = \frac{1}{2} \implies \angle A = 60^\circ.$$

建立坐标系:取 $A(0,0)$,$C(15,0)$,$B\left(\frac{7}{2}, \frac{7\sqrt{3}}{2}\right)$。

* **外心 $O$**:$x_O = \frac{15}{2}$,由 $OA = OB$ 得 $x_O + \sqrt{3} y_O = 7 \implies y_O = -\frac{\sqrt{3}}{6}$,即 $O\left(\frac{15}{2}, -\frac{\sqrt{3}}{6}\right)$。(验证 $R = \frac{a}{2\sin 60^\circ} = \frac{13}{\sqrt{3}}$。)
* **垂心 $H$**:由 $H = A + B + C - 2O$ 得 $H\left(\frac{7}{2}, \frac{23\sqrt{3}}{6}\right)$。
* **内心 $I$**:$s = \frac{13+15+7}{2} = \frac{35}{2}$,$x_I = s - a = \frac{9}{2}$,$y_I = r = \frac{\Delta}{s} = \frac{3\sqrt{3}}{2}$,即 $I\left(\frac{9}{2}, \frac{3\sqrt{3}}{2}\right)$。

于是 $\overrightarrow{OI} = \left(-3, \frac{5\sqrt{3}}{3}\right)$,$\overrightarrow{OH} = (-4, 4\sqrt{3})$,叉积绝对值为
$$\left|(-3)(4\sqrt{3}) - \frac{5\sqrt{3}}{3}(-4)\right| = \frac{16\sqrt{3}}{3}.$$
故 $\triangle OIH$ 的面积为 $\frac{8\sqrt{3}}{3}$(亦可用 $OI = IH = \sqrt{\frac{52}{3}}$、$OH = 8$ 交叉验证)。得 $m = 8, n = 3$,$m + n = \mathbf{11}$。

## 第 8 题(答案:15702)

所求为避开三对角禁用棋盘 $B_9 = \{(i, j) : |i - j| \le 1\}$ 的 9 阶排列数。设 $F_n(x) = \sum_{k=0}^{n} r_k(B_n) x^k$ 为 $B_n$ 的车多项式,$G_n(x)$ 为 $B_n$ 删去第 $n$ 行后的车多项式。

考察第 $n$ 行与第 $n$ 列的放车情况(均不放、放 $(n,n)$、仅放 $(n,n-1)$、仅放 $(n-1,n)$、同时放 $(n,n-1)$ 与 $(n-1,n)$),得:
$$F_n(x) = (1+x) F_{n-1}(x) + 2x G_{n-1}(x) + x^2 F_{n-2}(x), \qquad G_n(x) = F_{n-1}(x) + x G_{n-1}(x).$$
消去 $G_n(x)$ 得单一三阶递推:
$$F_n(x) = (1 + 2x) F_{n-1}(x) + x F_{n-2}(x) - x^3 F_{n-3}(x),$$
初值 $F_0 = 1$,$F_1 = 1 + x$,$F_2 = 1 + 4x + 2x^2$。逐步递推得到各阶系数(每步均经 $x = 1, -1, 2$ 及首末项校验):
* $F_3 = [1, 7, 11, 3]$
* $F_4 = [1, 10, 29, 26, 5]$
* $F_5 = [1, 13, 56, 94, 56, 8]$
* $F_6 = [1, 16, 92, 234, 263, 114, 13]$
* $F_7 = [1, 19, 137, 473, 815, 667, 223, 21]$
* $F_8 = [1, 22, 191, 838, 1982, 2504, 1577, 424, 34]$
* $F_9 = [1, 25, 254, 1356, 4115, 7191, 7018, 3538, 789, 55]$

由容斥原理:
$$a_9 = \sum_{k=0}^{9} (-1)^k r_k(B_9)(9-k)!$$
$$= (1\cdot 9! + 254\cdot 7! + 4115\cdot 5! + 7018\cdot 3! + 789\cdot 1!) - (25\cdot 8! + 1356\cdot 6! + 7191\cdot 4! + 3538\cdot 2! + 55\cdot 0!)$$
$$= (362880 + 1280160 + 493800 + 42108 + 789) - (1008000 + 976320 + 172584 + 7076 + 55)$$
$$= 2179737 - 2164035 = \mathbf{15702}.$$
