# Task 05: 地铁线路规划器 Notes

## 设计思路
- **单文件离线架构**：所有 HTML、CSS、JS 与示例线网数据全部内联于 `index.html`，无任何外部请求，支持直接 `file://` 打开运行。
- **双栏响应式布局与深色模式**：桌面端左侧为控制与换乘详情面板、右侧为可缩放平移的 SVG 线网图；移动端（`<= 820px`）自动切换为上下堆叠且无横向滚动条。通过 CSS 变量同时支持系统 `prefers-color-scheme: dark` 与手动切换按钮。
- **地图渲染**：根据输入坐标自适应缩放至 SVG `viewBox`，对并行共线段施加法向偏移以同时展示多条线路颜色，换乘站采用双环样式区分，并为站名标签提供多方向碰撞避让。

## 路径规划算法
- 采用基于**状态空间 `(stationIdx, lineIdx)` 的 Dijkstra 算法**（配合二叉最小堆）：
  - 在站点 `s` 处引入虚拟换乘中枢状态 `(s, -1)`，使得出站换乘耗费 `(transferTime(s), +1 transfer)`、进站乘车耗费 `(0, 0)`，将图规模严格控制在 `O(线路总站数)`，在 300 站规模下可在数毫秒内完成。
  - 支持双向运行、环线闭合、并行多线、`transferTime = 0` 的特殊站点以及不可达站点判断。
  - `"time"` 模式以 `(totalTime, transfers)` 为字典序最小目标；`"transfers"` 模式以 `(transfers, totalTime)` 为字典序最小目标。

## 已知不足
- 本机环境无可用浏览器自动化或 Node 运行权限，界面交互未通过无头浏览器截图实测，主要通过静态代码走查确认各接口与边界条件。
