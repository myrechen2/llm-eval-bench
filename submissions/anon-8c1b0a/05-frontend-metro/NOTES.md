# Task 05 · 城市轨道交通线路规划器说明

## 1. 设计思路

* **零依赖单文件架构**：全部 HTML 结构、响应式 CSS（含系统深色模式自适应与手动主题切换）、内联示例线网数据与核心逻辑均封装在单个 `index.html` 中，直接通过 `file://` 打开即可运行，不发起任何外部请求。
* **SVG 矢量交互地图**：
  * **自适应坐标缩放**：根据线网中所有站点的 `(x, y)` 边界盒自动计算缩放比例与居中偏移，适配任意正数坐标范围。
  * **并行区间偏移与环线闭合**：对共用同一相邻站点对的多条并行线路计算法向微偏移（parallel line offset），避免线条完全重叠遮挡；当 `loop: true` 时自动闭合末站与首站的区间线段。
  * **防重叠标签布局**：为每个站名评估 8 个候选方位，结合已放置标签包围盒碰撞惩罚与画布边界惩罚自动挑选最优标注方位，并叠加描边光晕（`paint-order: stroke fill`）确保跨线可读性。
  * **交互与响应式布局**：支持地图点击选站（带 `data-station-id`）、输入框联想与回车确认、模式切换、起终点一键互换、拖拽平移与滚轮/按钮缩放；在 `1440×900` 桌面端采用左栏控制面板 + 右侧全幅地图布局，在 `390×844` 移动端切换为上下单列流式布局，杜绝横向滚动条。

## 2. 路径规划算法说明

* **状态建模**：将搜索状态定义为三元组 `(stationId, lineId, phase)`：
  * `phase = 0`（已在该站登上 `lineId`，必须沿该线路至少乘坐 1 个区间）；
  * `phase = 1`（沿 `lineId` 乘车抵达该站，可继续沿该线乘车，或在该站换乘其它经过该站的线路 `lineId2 != lineId` 进入 `(stationId, lineId2, 0)`）。
  * 该两阶段状态拆分从根本上保证了即使某站点的 `transferTime` 为 `0`，也不会产生零站乘车区间（空 `leg`）或在同一站点连续无效换乘，确保输出的每一段 `leg` 至少包含一次真实区间移动，且相邻 `legs` 线路严格不同。
* **多关键字最短路（Dijkstra + 二叉最小堆）**：
  * 起点处将所有经过 `fromId` 的线路状态 `(fromId, lineId, 0)` 以代价 `(time=0, transfers=0, hops=0)` 入堆（上车不计耗时与换乘）。
  * 在 `"time"` 模式下按字典序最小化 `(totalTime, transfers, hops)`；在 `"transfers"` 模式下按字典序最小化 `(transfers, totalTime, hops)`。
  * 在站点 `s` 发生换乘时，严格检查 `s.transferTime !== undefined && s.transferTime !== null`（正确支持 `transferTime: 0`），否则回退到全局 `network.transferTime`。
  * 时间复杂度为 $O(E \log V)$，其中状态数 $V$ 不超过站点与线路关联对数的 2 倍；在 300～500 站规模下耗时小于 5 ms。

## 3. 已知不足

* 站名防重叠采用启发式贪心八方向局部评估，在极端高密度局部聚团（十余个站点坐标几乎重合）时仍可能出现轻微文字交叠，此时可通过地图放大功能查看细节。
