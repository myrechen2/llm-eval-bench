# Task 03 · 数学推理解答

## 1. 均值不等式求极值

将 $x + y + z = 6$ 拆分为 6 个正实数之和：
$$x + \frac{y}{2} + \frac{y}{2} + \frac{z}{3} + \frac{z}{3} + \frac{z}{3} = 6$$
由六元算术-几何均值不等式（AM-GM）：
$$1 = \frac{x + 2\cdot\frac{y}{2} + 3\cdot\frac{z}{3}}{6} \ge \left(x \cdot \left(\frac{y}{2}\right)^2 \cdot \left(\frac{z}{3}\right)^3\right)^{1/6} = \left(\frac{x y^2 z^3}{4 \times 27}\right)^{1/6}$$
故 $x y^2 z^3 \le 4 \times 27 = 108$，当且仅当 $x = \frac{y}{2} = \frac{z}{3} = 1$（即 $x=1, y=2, z=3$）时取等号。

**答案：** `108`

## 2. 相邻不同且数位和被 5 整除的四进制串计数

设 $\omega = e^{2\pi i / 5}$，对固定 $z = \omega^k$，记长为 $n$ 且相邻数字不同的加权和为
$$S_n(z) = \sum_{d_1 \neq d_2 \neq \cdots \neq d_n} z^{d_1 + \cdots + d_n}$$
- 当 $k = 0$（$z = 1$）时，$S_{10}(1) = 4 \times 3^9 = 78732$。
- 当 $k \in \{1, 2, 3, 4\}$ 时，$z$ 为 5 次本原单位根，对任意不被 5 整除的整数 $m$ 有 $\sigma_m = \sum_{d=0}^3 z^{md} = -z^{-m}$。
  转移矩阵 $M = D(J - I)$（其中 $D = \text{diag}(1, z, z^2, z^3)$）的特征多项式由矩阵行列式引理得：
  $$\chi_M(\lambda) = \lambda P'(\lambda) - 3P(\lambda) = \lambda^4 - z^3 \lambda^2 + 2z^2 \lambda - 3z$$
  其中 $P(\lambda) = \prod_{j=0}^3 (\lambda + z^j) = \frac{\lambda^5 + 1}{\lambda + z^4}$。
  令 $S_n(z) = z^{-n} b_n$，由 $z^5 = 1$ 可消去 $z$，得到与 $k \in \{1,2,3,4\}$ 无关的常系数整数递推：
  $$b_n = b_{n-2} - 2b_{n-3} + 3b_{n-4} \quad (n \ge 5)$$
  直接由初值递推：
  - $b_1 = -1$
  - $b_2 = 2$
  - $b_3 = -4$
  - $b_4 = 8$
  - $b_5 = -4 - 2(2) + 3(-1) = -11$
  - $b_6 = 8 - 2(-4) + 3(2) = 22$
  - $b_7 = -11 - 2(8) + 3(-4) = -39$
  - $b_8 = 22 - 2(-11) + 3(8) = 68$
  - $b_9 = -39 - 2(22) + 3(-11) = -116$
  - $b_{10} = 68 - 2(-39) + 3(22) = 212$
  当 $n = 10$ 时，$z^{-10} = 1$，故对每个 $k \in \{1,2,3,4\}$ 均有 $S_{10}(\omega^k) = 212$。

由单位根反演，所求数字串个数为：
$$N = \frac{1}{5}\left(4 \times 3^9 + 4 \times 212\right) = \frac{78732 + 848}{5} = \frac{79580}{5} = 15916$$

**答案：** `15916`

## 3. 满足 $f(f(f(x))) = f(x)$ 的函数计数

记值域 $I = f(S) \subseteq S$，$k = |I| \in \{1, \dots, 7\}$。条件 $\forall x \in S, f^3(x) = f(x)$ 等价于：
1. $f$ 在值域 $I$ 上的限制 $f|_I : I \to I$ 是对合置换（满足 $f(f(y)) = y$，即所有轮换长度为 1 或 2）；
2. 对每个 $x \in S \setminus I$，$f(x)$ 可在 $I$ 中任意取值（共 $k^{7-k}$ 种）。

设 $T_k$ 为 $k$ 元集合上的对合个数，满足 $T_0 = 1, T_1 = 1, T_k = T_{k-1} + (k-1)T_{k-2}$，依次为：
$$T_1 = 1,\ T_2 = 2,\ T_3 = 4,\ T_4 = 10,\ T_5 = 26,\ T_6 = 76,\ T_7 = 232$$
因此满足条件的函数总数为：
$$\sum_{k=1}^{7} \binom{7}{k} T_k k^{7-k} = 7\cdot 1\cdot 1 + 21\cdot 2\cdot 32 + 35\cdot 4\cdot 81 + 35\cdot 10\cdot 64 + 21\cdot 26\cdot 25 + 7\cdot 76\cdot 6 + 1\cdot 232\cdot 1$$
$$= 7 + 1344 + 11340 + 22400 + 13650 + 3192 + 232 = 52165$$

**答案：** `52165`

## 4. 被 3 整除且二进制 1 的个数也被 3 整除的整数计数

首先验证端点：$n = 2^{20}$ 的二进制只有 1 个 1，不满足条件；若改考虑 $0 \le n < 2^{20}$，其中 $n = 0$ 满足条件但不在 $[1, 2^{20}]$ 内，最后减去 1 即可。

对 $0 \le n < 2^{20}$，设其二进制偶数位（$2^0, 2^2, \dots, 2^{18}$，共 10 位）中 1 的个数为 $x$，奇数位（$2^1, 2^3, \dots, 2^{19}$，共 10 位）中 1 的个数为 $y$。
因 $2^{2i} \equiv 1 \pmod 3$，$2^{2i+1} \equiv -1 \pmod 3$，有：
- $3 \mid n \iff x - y \equiv 0 \pmod 3$
- $3 \mid \text{popcount}(n) \iff x + y \equiv 0 \pmod 3$

两式联立（在模 3 下 $\gcd(2,3)=1$）当且仅当：
$$x \equiv 0 \pmod 3 \quad \text{且} \quad y \equiv 0 \pmod 3$$
偶数位与奇数位完全独立，各自满足 $3 \mid x$ 的方案数为：
$$C = \binom{10}{0} + \binom{10}{3} + \binom{10}{6} + \binom{10}{9} = 1 + 120 + 210 + 10 = 341$$
去掉 $n = 0$，所求整数个数为：
$$C^2 - 1 = 341^2 - 1 = 116281 - 1 = 116280$$

**答案：** `116280`

## 5. 韦达跳跃方程 $\frac{a^2+b^2}{ab+1} = k$ 的解计数

由韦达跳跃（Vieta Jumping）知，$\frac{a^2+b^2}{ab+1} = k$ 有正整数解当且仅当 $k = m^2$（$m \in \mathbb{Z}^+$），且固定 $m$ 时所有非负整数解由递推序列
$$x_0 = 0,\quad x_1 = m,\quad x_{n+1} = m^2 x_n - x_{n-1} \quad (n \ge 1)$$
中的相邻项对 $(x_n, x_{n+1})$ 及 $(x_{n+1}, x_n)$（$n \ge 1$）给出。

在 $1 \le a, b \le 1000$ 范围内按 $m$ 枚举：
- $m = 1$：序列为 $0, 1, 1, 0$，唯一正整数解为 $(1, 1)$，共 **1** 个有序对；
- $m = 2$（$k = 4$）：序列为 $2, 8, 30, 112, 418, 1560, \dots$，在 $1000$ 以内的相邻无序对为 $\{2,8\}, \{8,30\}, \{30,112\}, \{112,418\}$，共 $4 \times 2 = \mathbf{8}$ 个有序对；
- $m = 3$（$k = 9$）：序列为 $3, 27, 240, 2133, \dots$，在 $1000$ 以内的相邻无序对为 $\{3,27\}, \{27,240\}$，共 $2 \times 2 = \mathbf{4}$ 个有序对；
- $m \in \{4, 5, 6, 7, 8, 9, 10\}$（共 7 个 $m$）：$x_2 = m^3 \le 1000$，而 $x_3 = m^5 - m \ge 4^5 - 4 = 1020 > 1000$，每个 $m$ 仅有 $\{m, m^3\}$ 一对，共 $7 \times 2 = \mathbf{14}$ 个有序对。

总计：$1 + 8 + 4 + 14 = 27$。

**答案：** `27`

## 6. $3 \times 12$ 矩形的多米诺与 $2 \times 2$ 方块铺砖计数

按列从左到右进行轮廓线动态规划。记第 $k$ 列向右伸入第 $k+1$ 列的被占行集合为 $S \subseteq \{1,2,3\}$：
- 当某列未占用格子集合 $S'$ 全部向右伸入下一列时：若 $S'$ 不含相邻行，只有全放横多米诺 1 种方式；若 $S'=\{1,2\}$ 或 $\{2,3\}$，可放两个横多米诺或一个 $2\times 2$ 方块，共 2 种方式；若 $S'=\{1,2,3\}$，可全放横多米诺或在上方/下方放一个 $2\times 2$ 方块，共 3 种方式。
- 从初始状态 $S = \emptyset$ 出发，可达状态按上下对称归并为：$a_k$（$S=\emptyset$）、$b_k$（$S=\{1\}$ 或 $\{3\}$）、$d_k$（$S=\{1,2\}$ 或 $\{2,3\}$）、$f_k$（$S=\{1,2,3\}$），转移关系为：
  $$a_{k+1} = 2b_k + f_k,\quad b_{k+1} = a_k + d_k,\quad d_{k+1} = 2b_k,\quad f_{k+1} = 3a_k$$
消去 $d_k, f_k$ 并令 $A_m = a_{2m}, B_m = b_{2m-1}$（$m \ge 1$，$A_0 = 1, B_0 = 0$）：
$$B_m = A_{m-1} + 2B_{m-1},\quad A_m = 3A_{m-1} + 2B_m$$
进一步消去 $B_m$ 得二阶常系数递推：
$$A_m = 7A_{m-1} - 6A_{m-2} \quad (A_0 = 1,\ A_1 = 5)$$
通项为 $A_m = \dfrac{4 \cdot 6^m + 1}{5}$。依次计算至 $m = 6$（即 $3 \times 12$）：
$$A_0 = 1,\ A_1 = 5,\ A_2 = 29,\ A_3 = 173,\ A_4 = 1037,\ A_5 = 6221,\ A_6 = 7 \times 6221 - 6 \times 1037 = 37325$$

**答案：** `37325`

## 7. 三角形 $OIH$ 的面积

在 $\triangle ABC$ 中，$c = AB = 7, a = BC = 13, b = CA = 15$。
由余弦定理：
$$\cos A = \frac{15^2 + 7^2 - 13^2}{2 \times 15 \times 7} = \frac{105}{210} = \frac{1}{2} \implies A = 60^\circ$$
半周长 $s = \frac{35}{2}$，面积 $\Delta = \frac{1}{2}bc\sin A = \frac{105\sqrt{3}}{4}$，内切圆半径 $r = \frac{\Delta}{s} = \frac{3\sqrt{3}}{2}$。

建立直角坐标系：令 $A(0,0)$，$B(7,0)$，则 $C\left(\frac{15}{2}, \frac{15\sqrt{3}}{2}\right)$：
- **外心 $O$**：由 $x_O = \frac{7}{2}$ 及 $OA^2 = OC^2$ 解得 $O\left(\frac{7}{2}, \frac{23}{2\sqrt{3}}\right)$；
- **垂心 $H$**：由 $H = A + B + C - 2O$ 得 $H\left(\frac{15}{2}, -\frac{1}{2\sqrt{3}}\right)$；
- **内心 $I$**：由 $I = \frac{aA + bB + cC}{a+b+c}$ 得 $I\left(\frac{9}{2}, \frac{9}{2\sqrt{3}}\right)$。

从而 $\vec{OI} = \left(1, -\frac{7}{\sqrt{3}}\right)$，$\vec{OH} = \left(4, -\frac{12}{\sqrt{3}}\right)$，故：
$$[OIH] = \frac{1}{2}\left|1 \cdot \left(-\frac{12}{\sqrt{3}}\right) - \left(-\frac{7}{\sqrt{3}}\right) \cdot 4\right| = \frac{1}{2} \cdot \frac{16}{\sqrt{3}} = \frac{8\sqrt{3}}{3}$$
（亦可用公式 $[OIH] = \dfrac{|(a-b)(b-c)(c-a)|}{8r} = \dfrac{2 \times 8 \times 6}{12\sqrt{3}} = \dfrac{8\sqrt{3}}{3}$ 直接验证。）
故 $m = 8, n = 3$（互素），$m + n = 11$。

**答案：** `11`

## 8. 满足 $|\pi(i) - i| \ge 2$ 的 9 元排列计数

禁止位置构成 $n \times n$ 三对角棋盘 $B_n = \{(i,j) : |i-j| \le 1\}$。设其车多项式为 $R_n(x) = \sum_{k=0}^n r_{n,k} x^k$，以及去掉最后一列后的辅助车多项式为 $S_n(x)$。
按最后一行与最后一列是否放车分类，有：
$$R_n(x) = (1+x)R_{n-1}(x) + x^2 R_{n-2}(x) + 2x S_{n-1}(x),\quad S_m(x) = R_{m-1}(x) + x S_{m-1}(x)$$
消去 $S$ 得到三阶递推：
$$R_n(x) = (1+2x)R_{n-1}(x) + x R_{n-2}(x) - x^3 R_{n-3}(x)$$
即系数满足 $r_{n,k} = r_{n-1,k} + 2r_{n-1,k-1} + r_{n-2,k-1} - r_{n-3,k-3}$。

由 $R_0(x)=1,\ R_1(x)=1+x,\ R_2(x)=1+4x+2x^2$ 逐层递推至 $n = 9$：
- $R_3(x) = 1 + 7x + 11x^2 + 3x^3$
- $R_4(x) = 1 + 10x + 29x^2 + 26x^3 + 5x^4$
- $R_5(x) = 1 + 13x + 56x^2 + 94x^3 + 56x^4 + 8x^5$
- $R_6(x) = 1 + 16x + 92x^2 + 234x^3 + 263x^4 + 114x^5 + 13x^6$
- $R_7(x) = 1 + 19x + 137x^2 + 473x^3 + 815x^4 + 667x^5 + 223x^6 + 21x^7$
- $R_8(x) = 1 + 22x + 191x^2 + 838x^3 + 1982x^4 + 2504x^5 + 1577x^6 + 424x^7 + 34x^8$
- $R_9(x) = 1 + 25x + 254x^2 + 1356x^3 + 4115x^4 + 7191x^5 + 7018x^6 + 3538x^7 + 789x^8 + 55x^9$

由容斥原理，满足条件的排列数为：
$$N_9 = \sum_{k=0}^{9} (-1)^k r_{9,k} (9-k)!$$
$$= 1\cdot 362880 - 25\cdot 40320 + 254\cdot 5040 - 1356\cdot 720 + 4115\cdot 120 - 7191\cdot 24 + 7018\cdot 6 - 3538\cdot 2 + 789\cdot 1 - 55\cdot 1$$
$$= 362880 - 1008000 + 1280160 - 976320 + 493800 - 172584 + 42108 - 7076 + 789 - 55 = 15702$$

**答案：** `15702`
