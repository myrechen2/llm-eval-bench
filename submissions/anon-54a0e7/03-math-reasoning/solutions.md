# Task 03 · 数学推理解答

## 第 1 题
**答案：`108`**

**推理过程：**
对正实数 $x, y, z$（满足 $x + y + z = 6$），将其拆为 6 个正数并应用算术-几何平均不等式（AM-GM）：
$$x + \frac{y}{2} + \frac{y}{2} + \frac{z}{3} + \frac{z}{3} + \frac{z}{3} = 6$$
这 6 项的算术平均为 $1$，故几何平均满足：
$$x \cdot \left(\frac{y}{2}\right)^2 \cdot \left(\frac{z}{3}\right)^3 \le 1^6 = 1$$
因此：
$$x y^2 z^3 \le 2^2 \cdot 3^3 = 4 \times 27 = 108$$
当且仅当 $x = \frac{y}{2} = \frac{z}{3} = 1$，即 $(x, y, z) = (1, 2, 3)$ 时取等号。最大值为 **$108$**。

## 第 2 题
**答案：`15916`**

**推理过程：**
做平移变换 $x_i = d_i + 1 \in \{1, 2, 3, 4\}$。由于串长 $n = 10$ 是 $5$ 的倍数，有：
$$d_1 + \dots + d_{10} \equiv 0 \pmod 5 \iff x_1 + \dots + x_{10} \equiv 0 \pmod 5$$
且相邻不同条件 $d_i \neq d_{i+1} \iff x_i \neq x_{i+1}$ 保持不变。

设 $\omega = e^{2\pi i / 5}$。对 $k \in \{1, 2, 3, 4\}$，四个非零余数上的权重集合均为全部本原五次单位根 $\{\zeta_1, \zeta_2, \zeta_3, \zeta_4\} = \{\omega, \omega^2, \omega^3, \omega^4\}$。
记转移矩阵 $\tilde{M} = (J - I) D_\zeta$，其中 $D_\zeta = \operatorname{diag}(\omega, \omega^2, \omega^3, \omega^4)$，$J = \mathbf{1}\mathbf{1}^T$。
令 $P(\lambda) = \prod_{j=1}^4 (\lambda + \zeta_j) = \lambda^4 - \lambda^3 + \lambda^2 - \lambda + 1$，由矩阵行列式引理，$\tilde{M}$ 的特征多项式为：
$$\chi(\lambda) = \det(\lambda I + D_\zeta - \mathbf{1}\mathbf{1}^T D_\zeta) = P(\lambda) - \sum_{j=1}^4 \zeta_j \prod_{i \neq j}(\lambda + \zeta_i) = \lambda P'(\lambda) - 3 P(\lambda) = \lambda^4 - \lambda^2 + 2\lambda - 3$$
对任意 $k \in \{1, 2, 3, 4\}$，记长度为 $n$ 的合法串指数和为 $S(n) = \sum_{x_1 \neq \dots \neq x_n} \omega^{k(x_1 + \dots + x_n)} = (\mathbf{1}^T D_\zeta) \tilde{M}^{n-1} \mathbf{1}$。
由 Cayley-Hamilton 定理，$S(n)$ 对 $n \ge 5$ 满足线性递推：
$$S(n) = S(n-2) - 2 S(n-3) + 3 S(n-4)$$
直接由幂和 $p_1 = p_2 = p_3 = p_4 = -1$ 计算前 4 项初值：
- $S(1) = p_1 = -1$
- $S(2) = p_1^2 - p_2 = 1 - (-1) = 2$
- $S(3) = -S(2) - (p_1 p_2 - p_3) = -2 - 2 = -4$
- $S(4) = (p_1 + p_2)^2 - (p_2 + 2p_3 + p_4) = 4 - (-4) = 8$

由递推关系依次计算至 $n = 10$：
- $S(5) = -4 - 2(2) + 3(-1) = -11$
- $S(6) = 8 - 2(-4) + 3(2) = 22$
- $S(7) = -11 - 2(8) + 3(-4) = -39$
- $S(8) = 22 - 2(-11) + 3(8) = 68$
- $S(9) = -39 - 2(22) + 3(-11) = -116$
- $S(10) = 68 - 2(-39) + 3(22) = 212$

而 $k = 0$ 时合法串总数为 $S_0(10) = 4 \times 3^9 = 78732$。由单位根筛选公式，所求数字串个数为：
$$N = \frac{1}{5}\left(S_0(10) + 4 S(10)\right) = \frac{78732 + 4 \times 212}{5} = \frac{79580}{5} = \mathbf{15916}$$

## 第 3 题
**答案：`52165`**

**推理过程：**
条件 $\forall x \in S,\; f(f(f(x))) = f(x)$ 等价于：在函数的值域 $I = f(S)$ 上，$f|_I: I \to I$ 满足 $f|_I^2 = \mathrm{id}_I$（即 $f|_I$ 是 $I$ 上的对合置换），而 $S \setminus I$ 中的每个元素只需映射到 $I$ 中的任意元素（由于 $f(I) = I$，这自动保证整个函数的值域恰好为 $I$）。

设 $|I| = k$（$1 \le k \le 7$）：
1. 选出大小非空为 $k$ 的子集 $I \subseteq S$，有 $\binom{7}{k}$ 种选法；
2. 在 $I$ 上指定一个对合置换 $\sigma: I \to I$，记 $k$ 元集上的对合数为 $a_k$（满足 $a_0 = a_1 = 1,\; a_k = a_{k-1} + (k-1)a_{k-2}$），依次为：
   $$a_1 = 1,\; a_2 = 2,\; a_3 = 4,\; a_4 = 10,\; a_5 = 26,\; a_6 = 76,\; a_7 = 232$$
3. 将 $S \setminus I$ 中的 $7 - k$ 个元素各自映射到 $I$ 中，有 $k^{7-k}$ 种选法。

因此满足条件的函数总数为：
$$\sum_{k=1}^7 \binom{7}{k} a_k k^{7-k}$$
逐项计算：
- $k = 1$: $7 \times 1 \times 1^6 = 7$
- $k = 2$: $21 \times 2 \times 2^5 = 1344$
- $k = 3$: $35 \times 4 \times 3^4 = 11340$
- $k = 4$: $35 \times 10 \times 4^3 = 22400$
- $k = 5$: $21 \times 26 \times 5^2 = 13650$
- $k = 6$: $7 \times 76 \times 6^1 = 3192$
- $k = 7$: $1 \times 232 \times 7^0 = 232$

求和得：
$$7 + 1344 + 11340 + 22400 + 13650 + 3192 + 232 = \mathbf{52165}$$

## 第 4 题
**答案：`116280`**

**推理过程：**
先考虑范围 $0 \le n \le 2^{20} - 1$（即 20 位二进制串 $b_{19}b_{18}\dots b_0$）。
由于 $2^k \equiv (-1)^k \pmod 3$：
- 设 10 个偶数位（$k \in \{0, 2, \dots, 18\}$）上 `1` 的个数为 $a$（$0 \le a \le 10$）；
- 设 10 个奇数位（$k \in \{1, 3, \dots, 19\}$）上 `1` 的个数为 $b$（$0 \le b \le 10$）。

则 $n \equiv a - b \pmod 3$，且二进制中 `1` 的个数为 $a + b$。
要求 $3 \mid n$ 且 $3 \mid (a + b)$，即：
$$\begin{cases} a - b \equiv 0 \pmod 3 \\ a + b \equiv 0 \pmod 3 \end{cases} \iff a \equiv 0 \pmod 3 \;\text{且}\; b \equiv 0 \pmod 3$$
在 $\{0, 1, \dots, 10\}$ 中满足模 3 余 0 的方案数为：
$$\binom{10}{0} + \binom{10}{3} + \binom{10}{6} + \binom{10}{9} = 1 + 120 + 210 + 10 = 341$$
偶数位与奇数位独立选择，故在 $0 \le n \le 2^{20} - 1$ 中共有 $341 \times 341 = 116281$ 个。
最后调整端点 $1 \le n \le 2^{20}$：去掉 $n = 0$（满足条件，减 $1$），而 $n = 2^{20}$ 的二进制仅有 1 个 `1`（不满足条件）。
因此共有 $116281 - 1 = \mathbf{116280}$ 个。

## 第 5 题
**答案：`27`**

**推理过程：**
由韦达跳跃（Vieta Jumping）原理，$\frac{a^2 + b^2}{ab + 1} = k$ 为正整数当且仅当 $k = d^2$（$d \ge 1$ 为正整数），且对固定的 $d \ge 1$，所有正整数解由线性递推序列：
$$x_0 = 0, \quad x_1 = d, \quad x_{m+1} = d^2 x_m - x_{m-1} \quad (m \ge 1)$$
中的相邻项 $(x_m, x_{m+1})$ 及 $(x_{m+1}, x_m)$ 给出。前几项显式为：
$$x_1 = d, \quad x_2 = d^3, \quad x_3 = d^5 - d, \quad x_4 = d^7 - 2d^3, \quad x_5 = d^9 - 3d^5 + d$$
枚举满足 $1 \le x_m, x_{m+1} \le 1000$ 的所有解：
1. **$d = 1$**：$x_1 = 1, x_2 = 1$（后续 $x_3 = 0$），仅给出 $1$ 个有序对 $(1, 1)$。
2. **$d = 2$**：序列为 $x_1 = 2, x_2 = 8, x_3 = 30, x_4 = 112, x_5 = 418$（$x_6 = 1560 > 1000$），包含 4 对相邻项 $\{2, 8\}, \{8, 30\}, \{30, 112\}, \{112, 418\}$，每对给出 2 个有序对，共 $4 \times 2 = 8$ 个。
3. **$d = 3$**：序列为 $x_1 = 3, x_2 = 27, x_3 = 240$（$x_4 = 2133 > 1000$），包含 2 对相邻项 $\{3, 27\}, \{27, 240\}$，共 $2 \times 2 = 4$ 个。
4. **$4 \le d \le 10$（共 7 个 $d$）**：$x_1 = d,\; x_2 = d^3 \le 1000$，而 $x_3 = d^5 - d \ge 1020 > 1000$，每个 $d$ 仅有 $\{d, d^3\}$ 一对相邻项，共 $7 \times 2 = 14$ 个。
5. **$d \ge 11$**：$x_2 = d^3 \ge 1331 > 1000$，无解。

合计共有 $1 + 8 + 4 + 14 = \mathbf{27}$ 个有序正整数对。

## 第 6 题
**答案：`37325`**

**推理过程：**
用 $1 \times 2$ 骨牌和 $2 \times 2$ 砖块铺满 $3 \times 2k$ 矩形，按每次推进 2 列建立状态转移：
- 设 $a_k$ 为铺满 $3 \times 2k$ 矩形（边界平齐）的方案数（$a_0 = 1$）；
- 设 $u_{2k}$ 为前 $2k-1$ 列铺满、第 $2k$ 列仅有顶格（或仅底格，按上下对称单侧计数）被占用的方案数（$u_0 = 0$）。

分析第 $2k-1, 2k$ 两列的铺法：
1. 进入单侧占用状态 $u_{2k}$：
   - 从平齐状态 $a_{k-1}$ 出发，在第 $2k-1$ 列放 1 个竖放 $1 \times 2$ 骨牌并在剩余一行放 1 个横放 $1 \times 2$ 骨牌伸入第 $2k$ 列，有 $a_{k-1}$ 种；
   - 从上一周期单侧状态 $u_{2k-2}$ 出发，在第 $2k-2, 2k-1$ 列的两个空行放入 1 个 $2 \times 2$ 砖块或 2 个并排横放 $1 \times 2$ 骨牌（共 2 种），迫使第 $2k-1$ 列剩余一行放横放 $1 \times 2$ 骨牌伸入第 $2k$ 列，有 $2 u_{2k-2}$ 种。
   故 $u_{2k} = a_{k-1} + 2 u_{2k-2}$。
2. 进入平齐状态 $a_k$：
   - 直接从 $a_{k-1}$ 在第 $2k-1, 2k$ 列横跨放置（3 个横放 $1 \times 2$，或上/下 1 个 $2 \times 2$ 配 1 个横放 $1 \times 2$，共 3 种），有 $3 a_{k-1}$ 种；
   - 从第 $2k$ 列单侧占用状态（顶格或底格各 $u_{2k}$ 种）在剩余两格补 1 个竖放 $1 \times 2$ 骨牌，有 $2 u_{2k}$ 种。
   故 $a_k = 3 a_{k-1} + 2 u_{2k}$。

消去 $u_{2k}$ 得二阶常系数递推 $a_k = 7 a_{k-1} - 6 a_{k-2}$（$a_0 = 1, a_1 = 5$），通项公式为：
$$a_k = \frac{4 \cdot 6^k + 1}{5}$$
依次计算至 $k = 6$（即 $3 \times 12$）：
- $a_1 = 5$
- $a_2 = 29$
- $a_3 = 173$
- $a_4 = 1037$
- $a_5 = 6221$
- $a_6 = \frac{4 \times 46656 + 1}{5} = \mathbf{37325}$

## 第 7 题
**答案：`11`**

**推理过程：**
设 $c = AB = 7,\; a = BC = 13,\; b = CA = 15$。
1. 由余弦定理：
   $$\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{225 + 49 - 169}{2 \times 15 \times 7} = \frac{105}{210} = \frac{1}{2} \implies A = 60^\circ$$
   从而外接圆半径 $R = \frac{a}{2\sin A} = \frac{13}{\sqrt{3}}$（即 $R^2 = \frac{169}{3}$），且：
   $$\sin B = \frac{b}{2R} = \frac{15\sqrt{3}}{26}, \quad \cos B = -\frac{1}{26}, \quad \sin C = \frac{c}{2R} = \frac{7\sqrt{3}}{26}, \quad \cos C = \frac{23}{26}$$
2. 以三角形外心 $O$ 为原点 $(0, 0)$，以 $BC$ 的垂直平分线为 $+x$ 轴建立直角坐标系：
   - 因 $\angle BOC = 2A = 120^\circ$，有 $B = R\left(\frac{1}{2}, -\frac{\sqrt{3}}{2}\right)$，$C = R\left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$；
   - 顶点 $A$ 与 $-x$ 轴的夹角为 $\phi = B - C$，其中：
     $$\sin\phi = \sin(B - C) = \frac{88\sqrt{3}}{169}, \quad \cos\phi = \cos(B - C) = \frac{73}{169}$$
     故 $A = R(-\cos\phi, \sin\phi) = \frac{R}{169}(-73, 88\sqrt{3})$。
3. 求垂心 $H$ 与内心 $I$ 的坐标：
   - 垂心 $H = A + B + C = R(1 - \cos\phi, \sin\phi) = \frac{R}{169}(96, 88\sqrt{3})$；
   - 内心 $I = \frac{aA + bB + cC}{a + b + c} = \frac{13A + 15B + 7C}{35} = \frac{R}{13}(2, 4\sqrt{3})$。
4. 计算 $\triangle OIH$ 的面积：
   $$S_{\triangle OIH} = \frac{1}{2} |x_I y_H - y_I x_H| = \frac{R^2}{2 \times 13 \times 169} \left| 2 \cdot 88\sqrt{3} - 4\sqrt{3} \cdot 96 \right| = \frac{169/3}{2 \times 13 \times 169} \cdot 208\sqrt{3} = \frac{8\sqrt{3}}{3}$$
因此 $m = 8,\; n = 3$（互素），$m + n = \mathbf{11}$。

## 第 8 题
**答案：`15702`**

**推理过程：**
条件 $\forall i,\; |\pi(i) - i| \ge 2$ 等价于在 $9 \times 9$ 棋盘上避开三对角禁位集合 $B = \{(i, j) : |i - j| \le 1\}$（共 $3 \times 9 - 2 = 25$ 个禁位）。
设 $R_n(x) = \sum_{k=0}^n r_k x^k$ 为 $n \times n$ 三对角禁位棋盘的车多项式（$r_k$ 为在 $B$ 上放置 $k$ 个互不攻击的车的方案数），$A_n(x)$ 为在此基础上第 $n$ 列未被占用的车多项式。
按行递推（第 $i$ 行可不放车，或放在第 $i-1, i, i+1$ 列），消去中间状态后得到耦合递推关系：
$$\begin{cases}
A_n(x) = R_{n-1}(x) + x A_{n-1}(x) \\
R_n(x) = (1 + x) R_{n-1}(x) + 2x A_{n-1}(x) + x^2 R_{n-2}(x)
\end{cases}$$
从 $R_0(x) = 1,\; A_1(x) = 1,\; R_1(x) = 1 + x$ 出发，依次递推至 $n = 9$：
- $R_2(x) = 1 + 4x + 2x^2$
- $R_3(x) = 1 + 7x + 11x^2 + 3x^3$
- $R_4(x) = 1 + 10x + 29x^2 + 26x^3 + 5x^4$
- $R_5(x) = 1 + 13x + 56x^2 + 94x^3 + 56x^4 + 8x^5$
- $R_6(x) = 1 + 16x + 92x^2 + 234x^3 + 263x^4 + 114x^5 + 13x^6$
- $R_7(x) = 1 + 19x + 137x^2 + 473x^3 + 815x^4 + 667x^5 + 223x^6 + 21x^7$
- $R_8(x) = 1 + 22x + 191x^2 + 838x^3 + 1982x^4 + 2504x^5 + 1577x^6 + 424x^7 + 34x^8$
- $A_8(x) = 1 + 20x + 154x^2 + 579x^3 + 1116x^4 + 1061x^5 + 435x^6 + 54x^7$
- $R_9(x) = 1 + 25x + 254x^2 + 1356x^3 + 4115x^4 + 7191x^5 + 7018x^6 + 3538x^7 + 789x^8 + 55x^9$

由容斥原理，满足条件的排列数为：
$$\begin{aligned}
N &= \sum_{k=0}^9 (-1)^k r_k (9 - k)! \\
  &= 1 \cdot 362880 - 25 \cdot 40320 + 254 \cdot 5040 - 1356 \cdot 720 + 4115 \cdot 120 \\
  &\quad - 7191 \cdot 24 + 7018 \cdot 6 - 3538 \cdot 2 + 789 \cdot 1 - 55 \cdot 1 \\
  &= (362880 + 1280160 + 493800 + 42108 + 789) - (1008000 + 976320 + 172584 + 7076 + 55) \\
  &= 2179737 - 2164035 = \mathbf{15702}
\end{aligned}$$
