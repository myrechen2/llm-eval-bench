# Task 03 — 数学推理题解

## 第 1 题（答案：108）
由算术-几何平均不等式（AM-GM），对 6 个正数 $x, \frac{y}{2}, \frac{y}{2}, \frac{z}{3}, \frac{z}{3}, \frac{z}{3}$：
$$\left(x \cdot \left(\frac{y}{2}\right)^2 \cdot \left(\frac{z}{3}\right)^3\right)^{1/6} \le \frac{x + y + z}{6} = 1,$$
故 $x y^2 z^3 \le 2^2 \cdot 3^3 = 108$。当且仅当 $x = \frac{y}{2} = \frac{z}{3} = 1$（即 $x=1, y=2, z=3$）时取等号。

## 第 2 题（答案：15916）
设 $\omega = e^{2\pi i / 5}$，对每个 5 次单位根 $z \in \{1, \omega, \omega^2, \omega^3, \omega^4\}$，令 $T_k(z) = \sum_{\text{合法串 } d} z^{\sum_{j=1}^k d_j}$，由单位根滤子得答案为
$$N = \frac{1}{5} \sum_{j=0}^{4} T_{10}(\omega^j)。$$
* 当 $z = 1$ 时，首位 4 种选法，其余 9 位各 3 种选法，故 $T_{10}(1) = 4 \cdot 3^9 = 78732$。
* 当 $z \neq 1$ 时，设 $x_k(a)$ 为长度 $k$ 且末位为 $a \in \{0,1,2,3\}$ 的合法串的权重和，则 $x_1(a) = z^a$，$x_{k+1}(a) = z^a (T_k - x_k(a))$。设生成函数 $X_a(t) = \sum_{k\ge 1} x_k(a) t^k$，$T(t) = \sum_{k\ge 1} T_k t^k$，整理得
  $$(1 + z^a t) X_a(t) = z^a t (1 + T(t)) \implies 1 + T(t) = \frac{1}{1 - R(t)},$$
  其中 $R(t) = \sum_{a=0}^3 \frac{z^a t}{1 + z^a t} = \frac{5t^5}{1+t^5} - \frac{wt}{1+wt}$（令 $w = z^4$）。化简并利用 $w^5 = 1$ 得
  $$1 + T(t) = \frac{(1+t^5)(1+wt)}{1 + 2wt - 4t^5 - 3wt^6}。$$
  展开求 $t^{10}$ 系数（设 $a_0=1, a_k=T_k$）：
  $a_1=-w,\ a_2=2w^2,\ a_3=-4w^3,\ a_4=8w^4,\ a_5=1+4-16w^5=-11$；
  此后由 $a_k = -2w a_{k-1} + 4a_{k-5} + 3w a_{k-6}$（其中 $a_6$ 加上分子项 $w$）递推：
  $a_6 = 22w,\ a_7 = -39w^2,\ a_8 = 68w^3,\ a_9 = -116w^4,\ a_{10} = 232 - 44 + 24 = 212$（与 $w$ 无关）。

因此 $N = \frac{78732 + 4 \times 212}{5} = \frac{79580}{5} = 15916$。

## 第 3 题（答案：52165）
设 $I = f(S)$，$|I| = k \in \{1, \dots, 7\}$。条件 $f(f(f(x))) = f(x)$ 等价于 $f|_I : I \to I$ 满足 $f^2|_I = \mathrm{id}_I$（即 $f|_I$ 是 $I$ 上的对合），且对 $x \in S \setminus I$ 可以任意取 $f(x) \in I$。反之任意选取 $(I, \sigma, g: S \setminus I \to I)$ 都唯一确定满足条件的函数。

$k$ 元集上的对合数 $a_k$ 满足 $a_0=a_1=1,\ a_k = a_{k-1} + (k-1)a_{k-2}$，故
$a_1=1,\ a_2=2,\ a_3=4,\ a_4=10,\ a_5=26,\ a_6=76,\ a_7=232$。

总数为
$$\sum_{k=1}^7 \binom{7}{k} a_k k^{7-k} = 7\cdot 1\cdot 1 + 21\cdot 2\cdot 32 + 35\cdot 4\cdot 81 + 35\cdot 10\cdot 64 + 21\cdot 26\cdot 25 + 7\cdot 76\cdot 6 + 1\cdot 232\cdot 1$$
$$= 7 + 1344 + 11340 + 22400 + 13650 + 3192 + 232 = 52165。$$

## 第 4 题（答案：116280）
注意到 $n = 2^{20} \equiv 1 \pmod 3$ 不满足条件，故只需统计 $0 \le n < 2^{20}$ 中满足条件者再减去 $n = 0$。

将 $n = \sum_{k=0}^{19} b_k 2^k$ 的 20 个二进制位分为 10 个偶数位与 10 个奇数位，分别有 $e$ 个和 $o$ 个 $1$（$0 \le e, o \le 10$）。因 $2^k \equiv (-1)^k \pmod 3$，有
$$n \equiv e - o \pmod 3, \qquad \text{popcount}(n) = e + o。$$
故 $3 \mid n$ 且 $3 \mid (e+o)$ 当且仅当 $e - o \equiv 0$ 且 $e + o \equiv 0 \pmod 3$，即 $3 \mid e$ 且 $3 \mid o$。

10 个位置中选出模 3 余 0 个 1 的方案数为
$$E = \binom{10}{0} + \binom{10}{3} + \binom{10}{6} + \binom{10}{9} = 1 + 120 + 210 + 10 = 341 = \frac{2^{10}-1}{3}。$$
因此所求个数为 $E^2 - 1 = 341^2 - 1 = 340 \times 342 = 116280$。

## 第 5 题（答案：27）
设 $\frac{a^2 + b^2}{ab + 1} = k \in \mathbb{Z}_{>0}$，即 $a^2 - kab + b^2 = k$。
对给定 $k$，考虑非负整数解中 $a + b$ 最小者（不妨设 $a \ge b \ge 0$）。由韦达定理，关于 $a$ 的二次方程另一根为 $x_2 = kb - a = \frac{b^2 - k}{a} \in \mathbb{Z}$。
* 若 $b \ge 1$，则不可能有 $x_2 > 0$（否则 $x_2 < \frac{b^2}{a} \le b \le a$ 违背最小性），也不可能有 $x_2 \le -1$（否则 $x_2^2 - kb x_2 + b^2 - k \ge 1 + kb + 1 - k \ge 2 > 0$）。因此必有 $x_2 = 0$，即 $k = b^2$（$k$ 必为平方数 $m^2$）。
* 于是所有正整数解均来自 $m \ge 1$ 的递推链 $x_0 = 0,\ x_1 = m,\ x_{n+1} = m^2 x_n - x_{n-1}$ 的相邻项 $(x_n, x_{n+1})$（$n \ge 1$）：
  * $m = 1$：序列为 $0, 1, 1, 0, \dots$，给出唯一正整数解 $(1, 1)$（1 对）。
  * $m = 2$：$x_1=2, x_2=8, x_3=30, x_4=112, x_5=418, x_6=1560 > 1000$，给出 $\{2,8\}, \{8,30\}, \{30,112\}, \{112,418\}$，计 $4 \times 2 = 8$ 个有序对。
  * $m = 3$：$x_1=3, x_2=27, x_3=240, x_4=2133 > 1000$，给出 $\{3,27\}, \{27,240\}$，计 $2 \times 2 = 4$ 个有序对。
  * $4 \le m \le 10$：$x_2 = m^3 \le 1000$ 而 $x_3 = m^5 - m \ge 1020 > 1000$，这 7 个 $m$ 各给出 $\{m, m^3\}$，计 $7 \times 2 = 14$ 个有序对。
  * $m \ge 11$：$m^3 > 1000$，无解。

合计 $1 + 8 + 4 + 14 = 27$ 个有序正整数对。

## 第 6 题（答案：37325）
按列从左到右进行轮廓线（状态压缩）动态规划。每块砖面积均为偶数（2 或 4），故填满奇数列后跨过边界的已覆盖格数必为奇数，填满偶数列后必为偶数。在可达态中，中间单格突出的状态 `010` 与 `101` 相互独立且不可从 `000` 到达，从而偶数列边界仅出现 `000`（记方案数为 $a_{2m}$）与对称状态 `{110, 011}`（记总方案数为 $B_{2m}$）；奇数列边界仅出现 `{001, 100}`（记为 $C_{2m+1}$）与 `111`（记为 $D_{2m+1}$）。

列转移：
* 从偶数列到奇数列：
  * 从 `000` 出发：放 1 个竖骨牌+1 个横骨牌得 `001` 或 `100`（各 1 种）；跨列全伸出有 3 种（3 个横骨牌，或上/下 $2\times 2$ 正方形配 1 个横骨牌）得 `111`。
  * 从 `110` 或 `011` 出发：剩余 1 格只能放横骨牌到 `001` 或 `100`（各 1 种）。
  故 $C_{2m+1} = 2a_{2m} + B_{2m}$，$\ D_{2m+1} = 3a_{2m}$。
* 从奇数列到偶数列：
  * 从 `001` 或 `100` 出发：放 1 个竖骨牌回 `000`（1 种）；放 2 个横骨牌或 1 个 $2\times 2$ 正方形至 `110`/`011`（2 种）。
  * 从 `111` 出发：不放砖直接回 `000`（1 种）。
  故 $a_{2m+2} = C_{2m+1} + D_{2m+1} = 5a_{2m} + B_{2m}$，$\ B_{2m+2} = 2C_{2m+1} = 4a_{2m} + 2B_{2m}$。

由 $a_0 = 1, B_0 = 0$，可见 $B_{2m+2} - a_{2m+2} = B_{2m} - a_{2m} = -1$，从而 $a_{2m+2} = 6a_{2m} - 1$，通项 $a_{2m} = \frac{4\cdot 6^m + 1}{5}$。
逐步递推至 $n = 12$（$m = 6$）：
$a_0 = 1,\ a_2 = 5,\ a_4 = 29,\ a_6 = 173,\ a_8 = 1037,\ a_{10} = 6221,\ a_{12} = 37325$。

## 第 7 题（答案：11）
设 $a = BC = 13, b = CA = 15, c = AB = 7$，半周长 $s = \frac{35}{2}$。
由余弦定理，$\cos A = \frac{15^2 + 7^2 - 13^2}{2\cdot 15\cdot 7} = \frac{105}{210} = \frac{1}{2}$，故 $A = 60^\circ$；而 $\cos B = \frac{13^2 + 7^2 - 15^2}{2\cdot 13\cdot 7} = -\frac{1}{26} < 0$（钝角在 $B$）。
三角形面积 $\Delta = \frac{1}{2}bc\sin A = \frac{105\sqrt{3}}{4}$，外接圆半径 $R = \frac{a}{2\sin A} = \frac{13}{\sqrt{3}}$，内切圆半径 $r = \frac{\Delta}{s} = \frac{3\sqrt{3}}{2}$。

建立直角坐标系：$A=(0,0)$，$C=(15,0)$，$B=\left(\frac{7}{2}, \frac{7\sqrt{3}}{2}\right)$。
* **外心 $O$**：在 $AC$ 中垂线 $x = \frac{15}{2}$ 上，且因 $\angle B > 90^\circ$ 位于 $AC$ 异侧（$y_O < 0$）。由 $(\frac{15}{2})^2 + y_O^2 = R^2 = \frac{169}{3}$ 得 $y_O^2 = \frac{1}{12}$，故 $O = \left(\frac{15}{2}, -\frac{\sqrt{3}}{6}\right)$。
* **垂心 $H$**：$H = A + B + C - 2O = \left(\frac{7}{2}, \frac{7\sqrt{3}}{2} + \frac{\sqrt{3}}{3}\right) = \left(\frac{7}{2}, \frac{23\sqrt{3}}{6}\right)$。
* **内心 $I$**：$x_I = s - a = \frac{9}{2}$，$y_I = r = \frac{3\sqrt{3}}{2}$，故 $I = \left(\frac{9}{2}, \frac{3\sqrt{3}}{2}\right)$。

得向量 $\overrightarrow{OI} = \left(-3, \frac{5\sqrt{3}}{3}\right)$，$\overrightarrow{OH} = (-4, 4\sqrt{3})$，叉积为
$$\overrightarrow{OI} \times \overrightarrow{OH} = (-3)(4\sqrt{3}) - \left(\frac{5\sqrt{3}}{3}\right)(-4) = -\frac{16\sqrt{3}}{3}。$$
故 $[OIH] = \frac{1}{2} \left|-\frac{16\sqrt{3}}{3}\right| = \frac{8\sqrt{3}}{3}$（也可由 $[OIH] = \frac{|(a-b)(b-c)(c-a)|}{8r} = \frac{96}{12\sqrt{3}} = \frac{8\sqrt{3}}{3}$ 印证）。
$m = 8, n = 3$ 互素，故 $m + n = 11$。

## 第 8 题（答案：15702）
设禁用棋盘 $B_n = \{(i, j) \in \{1..n\}^2 : |i - j| \le 1\}$，其车多项式为 $f_n(x) = \sum_{k=0}^n r_k x^k$，由容斥原理有 $D_2(n) = \sum_{k=0}^n (-1)^k r_k (n-k)!$。

按 $B_n$ 中车的放置对应于将 $\{1, \dots, n\}$ 划分为若干连续区间（每个连通分量可为长度 1 的空点/自环 $(1+x)y$、长度 2 的二元环或单向边 $(2x+x^2)y^2$，或长度 $L \ge 3$ 的单调增/减有向路 $2x^{L-1} y^L$），单块生成函数为
$$W(y, x) = (1+x)y + x^2 y^2 + \frac{2xy^2}{1 - xy},$$
从而 $\sum_{n \ge 0} f_n(x) y^n = \frac{1}{1 - W(y,x)} = \frac{1 - xy}{1 - (1+2x)y - xy^2 + x^3 y^3}$。
于是对 $n \ge 3$ 有线性递推：
$$f_n(x) = (1+2x)f_{n-1}(x) + x f_{n-2}(x) - x^3 f_{n-3}(x)，$$
初值 $f_0=1,\ f_1=1+x,\ f_2=1+4x+2x^2$。依次算得：
* $f_3 = 1 + 7x + 11x^2 + 3x^3$
* $f_4 = 1 + 10x + 29x^2 + 26x^3 + 5x^4$
* $f_5 = 1 + 13x + 56x^2 + 94x^3 + 56x^4 + 8x^5$
* $f_6 = 1 + 16x + 92x^2 + 234x^3 + 263x^4 + 114x^5 + 13x^6$
* $f_7 = 1 + 19x + 137x^2 + 473x^3 + 815x^4 + 667x^5 + 223x^6 + 21x^7$
* $f_8 = 1 + 22x + 191x^2 + 838x^3 + 1982x^4 + 2504x^5 + 1577x^6 + 424x^7 + 34x^8$
* $f_9 = 1 + 25x + 254x^2 + 1356x^3 + 4115x^4 + 7191x^5 + 7018x^6 + 3538x^7 + 789x^8 + 55x^9$

代入容斥公式计算 $D_2(9)$：
$$\begin{aligned}
D_2(9) &= 1\cdot 9! - 25\cdot 8! + 254\cdot 7! - 1356\cdot 6! + 4115\cdot 5! - 7191\cdot 4! + 7018\cdot 3! - 3538\cdot 2! + 789\cdot 1! - 55\cdot 0! \\
&= 362880 - 1008000 + 1280160 - 976320 + 493800 - 172584 + 42108 - 7076 + 789 - 55 \\
&= 2179737 - 2164035 = 15702。
\end{aligned}$$
