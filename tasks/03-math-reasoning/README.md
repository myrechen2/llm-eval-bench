# 任务 03 · 数学推理(竞赛 / HLE 类,禁止工具)

**对标:** AIME 2025/2026、HMMT、Humanity's Last Exam(无工具设置)。考察纯推理能力——这是"思考强度"差异通常最明显的一类任务。

## 规则(重要)

* **禁止运行任何代码、计算器、符号计算工具或联网搜索**来求解或验证本任务。只能靠你自己的推理。
* 这些题目是新写的,网上没有现成答案。
* 如果你违反了规则(哪怕只是用代码"验证一下"),请如实在 `answers.json` 中把 `"used_tools"` 设为 `true`,这比隐瞒更好。

## 题目

所有答案都是**非负整数**。

**1.** 正实数 $x, y, z$ 满足 $x + y + z = 6$。求 $x \cdot y^2 \cdot z^3$ 的最大值。

**2.** 考虑长度为 10、每位取自 $\{0,1,2,3\}$ 的数字串(允许首位为 0),要求任意两个相邻位置上的数字不同,且所有数字之和能被 5 整除。这样的数字串有多少个?

**3.** 设 $S = \{1,2,3,4,5,6,7\}$。有多少个函数 $f: S \to S$ 满足对所有 $x \in S$ 都有 $f(f(f(x))) = f(x)$?

**4.** 有多少个整数 $n$ 满足 $1 \le n \le 2^{20}$,$n$ 能被 3 整除,并且 $n$ 的二进制表示中 1 的个数也能被 3 整除?

**5.** 有多少个有序正整数对 $(a, b)$ 满足 $1 \le a, b \le 1000$,且 $\dfrac{a^2 + b^2}{ab + 1}$ 是整数?

**6.** 用 $1\times 2$ 的多米诺骨牌(可横放或竖放)和 $2 \times 2$ 的正方形砖块,不重叠、无空隙地铺满一个 $3 \times 12$ 的矩形(3 行 12 列)。共有多少种铺法?(仅形状、位置不同才算不同;同种砖块之间不区分。)

**7.** 三角形 $ABC$ 中,$AB = 7$,$BC = 13$,$CA = 15$。设 $O, I, H$ 分别为其外心、内心、垂心。三角形 $OIH$ 的面积可以写成 $\dfrac{m\sqrt{3}}{n}$,其中 $m, n$ 为互素正整数。求 $m + n$。

**8.** 有多少个 $\{1, 2, \dots, 9\}$ 的排列 $\pi$,使得对每个 $i$ 都有 $|\pi(i) - i| \ge 2$?
