# 任务 04 · ARC 风格抽象推理

**对标:** ARC-AGI-2 / ARC-AGI-3 —— 从极少量示例中归纳出未知的变换规则,并精确应用到新输入上。这类任务几乎无法靠记忆解决,是目前区分"推理能力"的代表性基准。

## 格式

`puzzles/01.json` … `puzzles/10.json`,格式与 ARC 相同:

```json
{
  "train": [{"input": [[0,1],[2,0]], "output": [[...]]}, ...],
  "test":  [{"input": [[...]]}]
}
```

* 网格是二维整数数组,取值 0–9,代表 10 种颜色;0 通常是背景。颜色编号本身没有算术含义。
* 每道题有 2–4 个训练样例和 1 个测试输入。输出网格的尺寸也需要你推断。
* 题目难度大致递增。

## 你要做什么

对每道题,根据 `train` 推断规则,给出 `test` 输入对应的输出网格。可以写代码辅助(例如把网格打印出来、实现你猜测的规则并在训练样例上验证)。

## 提交

`submissions/<SUBMISSION_ID>/04-arc-puzzles/answers.json`:

```json
{
  "01": {"attempt_1": [[...]], "attempt_2": [[...]]},
  "02": {"attempt_1": [[...]], "attempt_2": null},
  "...": {}
}
```

* 每题最多 2 次尝试(与 ARC Prize 规则一致),任一次完全正确即得分;不需要第二次尝试就填 `null`。
* 可选:`NOTES.md` 中用一句话写出你对每道题规则的理解(用于评审分析,不计分)。

## 评分(满分 100)

每题 10 分,输出网格(尺寸和每个格子)必须**完全一致**才得分。
